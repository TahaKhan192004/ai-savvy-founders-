What this skill does

  • Rewrites AI-sounding text so it reads like a person wrote it, without dropping a fact, a name, a number, or a claim from the original.
  • Catches the stock tells: "serves as" where "is" would do, trailing clauses that editorialize, forced triples, inline bold bullet lists, filler paragraphs about legacy or significance.
  • Rewrites paragraph by paragraph, not phrase by phrase, so the underlying rhythm actually changes instead of just swapping a few words.
  • If you hand it a writing sample, that sample sets the target voice: sentence length, punctuation habits, and word choice all match it.
  • Has to be invoked. It does not run on every message, and it steps aside for a brand voice skill already handling the same draft.

Note

Both platforms use the same skill package. Download it once and install it wherever you draft.

Install in Claude

01

Download the skill package

Grab the ZIP file below. It contains the skill instructions and its reference files.

Download humanizer-skill.zip PASTE-DIRECT-DOWNLOAD-LINK-HERE
02

Open the Skills panel

In the left sidebar, click Customize, then click Skills.

03

Upload the skill

  • a.Click the + button in the Skills panel.
  • b.Select + Create skill.
  • c.Select Upload a skill and choose the ZIP file you downloaded in step one.

Install in ChatGPT

01

Open Plugins

In the ChatGPT sidebar, select Plugins.

02

Select the Skills tab

In the Plugin Directory, select the Skills tab, next to Plugins.

03

Upload the file

  • a.Select Create.
  • b.Select Upload from your computer, not Create with chat or Create with editor. Those two build a new skill from scratch, this one is already built.
  • c.Choose the skill file you downloaded in the Claude section above.
04

Let it scan and confirm

ChatGPT scans every uploaded skill before it goes live. Once the scan clears, Humanizer appears under Created by me on the Skills page.

Note

Skills availability in ChatGPT depends on your plan and workspace settings. If the Skills tab is missing, check your plan first.

Using it after install

The skill will not touch your writing on its own. Ask for it by name, or describe what you want:

  • "Humanize this paragraph."
  • "This reads like AI wrote it, fix that."
  • "Run the humanizer skill on this caption before I post it."

Paste in a sample of your own past writing first if you want the rewrite to match your voice exactly. That sample overrides every default in the skill.

FAQ

Does it run automatically on everything I write?

No. It has to be invoked. Ask for it by name or describe what you want fixed, and it runs on that request only.

Will it change what my writing says?

No. Every claim, name, number, date, and quote from the original stays in the rewrite. Only the sound and rhythm of the sentences change.

Does it conflict with a brand voice skill I already use?

No. It hands tone, structure, and calls to action to whichever brand voice skill is already handling the draft, and only applies the rules that do not fight it.

Do I need a paid plan to upload it?

In Claude, skill upload works on Free, Pro, Max, Team, and Enterprise plans once Code execution and file creation is turned on. In ChatGPT, check the Skills tab under Plugins first, since availability depends on your plan and workspace.
