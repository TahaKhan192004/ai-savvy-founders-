01

Before You Start

You need an active Claude Pro, Team, or Enterprise subscription. The free plan does not support skills, MCPs, or plugins.

Open claude.ai in your browser and confirm you are logged in to your paid account.

IMPORTANT

Each section below is independent. You can install them in any order. Start with whichever category matches your biggest need right now.

02

Install Skills (7)

Skills are custom instruction sets that teach Claude specific workflows. They live inside your projects and activate automatically when relevant.

TIP

You can browse and install skills by typing / in the message bar and selecting "Add a skill." You can also search the skill library from inside any project's settings.

How to install a skill:

a. Open any chat or project in Claude
b. Type / in the message bar
c. Search for the skill by name
d. Click Add to install it

03

Connect MCPs (8)

MCPs (Model Context Protocol connectors) are live wires between Claude and your existing tools. Once connected, Claude can read, write, and take actions inside those tools without you copying and pasting anything.

How to connect an MCP:

a. Click the + icon next to the message bar
b. Select Connect Apps
c. Search for the connector by name
d. Click Connect and authorize with your account credentials
e. Grant the requested permissions when prompted
NOTE

MCPs connect at the account level. Once connected, they are available across all your projects and chats.

Add Plugins (8)

Plugins are pre-built toolkits that bundle multiple capabilities into a single install. Unlike skills (which are instruction sets), plugins give Claude access to new tools and commands.

How to install a plugin:

a. Open a chat in Claude

c. Search for the plugin by name
d. Click Install to add it to your account

Turn On Built-in Features (7)

These are features that already exist inside Claude. They do not require installing anything, but some are turned off by default or need to be accessed from specific menus.

ME
Memory
Stops re-explaining your context every session.
PJ
Projects
A dedicated space per recurring workflow.
AR
Artifacts
For anything you want to see, edit, and keep.
CC
Claude Code
Worth learning even if you're not "technical."
CH
Claude in Chrome
Lets Claude act inside your browser directly.
CW
Cowork
Delegate multi-step work tasks, hands-off.
EX
Claude in Excel
Spreadsheet work without leaving the sheet.

How to enable each one:

Feature Where to find it What to do
Memory Settings > Profile Toggle "Memory" on. Claude starts learning from your conversations.
Projects Left sidebar Click + New Project. Add instructions, files, and skills.
Artifacts Settings > Features Toggle "Create and analyze artifacts" on. Claude generates visual outputs.
Claude Code Claude Desktop app Open the Code tab in the desktop app. No terminal required.
Claude in Chrome Chrome Web Store Install the extension. Claude can read and act on pages you visit.
Cowork Claude Desktop app Open the Cowork tab. Assign multi-step tasks that run in the background.
Claude in Excel Microsoft Add-ins Install from the Excel add-in store. Claude works inside your spreadsheet.

Verify Your Setup

After installing everything, run a quick check to confirm each category is working.

Test your skills:

Test prompt
What skills do you have access to right now? List them.

Test your MCPs:

Test prompt
Which MCP connectors are currently active? Try reading the most recent file from my Google Drive.

Test your plugins:

Test prompt
What plugins do I have installed? Run a quick check.
TIP

If Claude does not recognize a skill or plugin, try refreshing the page. Some installs take a few seconds to propagate.

Troubleshooting

Problem Likely Cause Fix
Skill not showing up Not added to the current project Open project settings and add the skill manually
MCP says "not connected" Authorization expired Go to Connect Apps, find the connector, click Reconnect
MCP permissions error Insufficient permissions granted Disconnect and reconnect, granting all requested permissions
Plugin not recognized Install did not complete Refresh the page. If it persists, search for the plugin and install again
Claude Code tab missing Using web app instead of desktop Download and open the Claude desktop app
Memory not saving context Feature toggled off Go to Settings > Profile and toggle Memory on
Cowork not available Not on a supported plan Verify your subscription includes Cowork access
