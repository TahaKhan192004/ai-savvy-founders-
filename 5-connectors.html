The short version

Claude connectors let Claude read and act inside the apps your business already runs on. This SOP sets up five of them: Composio for Gmail, Calendar, Notion, CRM and Slack actions, Apify for LinkedIn and Instagram data, Clay for lead enrichment, Fathom for call notes, and Higgsfield for video and image production.

Who this is for: founders and operators who want Claude doing real work, not only answering questions.

Tools needed: a Claude account, plus an account with each of the five tools below.

01

Before you start

Every connector below follows the same pattern. Learn it once and the other five steps go fast.

  1. Open Claude and click your profile name, then Settings.
  2. Click Connectors in the settings list.
  3. Click Browse connectors and search for the tool by name. If it appears, click Connect and approve the sign-in window.
  4. If the tool is not listed, click Add custom connector, enter the tool name, and paste the remote server URL from that tool's documentation.
  5. Open a new chat, click the + or tools menu in the message box, and confirm the connector is switched on for that chat.
  6. Run the test prompt for that tool. Always start with a read-only prompt before you let Claude write, send or publish anything.
Important

Menu names can shift as Claude updates. If a button has moved, search for "connectors" in Claude's settings search box and follow the same pattern.

02

Set up Composio

Composio gives Claude hands inside Gmail, Calendar, Notion, your CRM and Slack through one connection.

Connect it

  1. Create or log in to your account at the link below. Composio
    composio.dev
  2. In Claude, go to Settings, then Connectors, and search for Composio.
  3. Click Connect and approve the sign-in window. If Composio is not listed, copy the remote MCP URL from your Composio dashboard and use Add custom connector.
  4. Back in Claude, start a chat and ask it to connect your apps one at a time. Claude will return an authorisation link for each app.
  5. Authorise these five apps: Gmail, Google Calendar, Notion, your CRM, and Slack.
  6. For each app, grant the minimum permissions you need. Choose read access first if the screen gives you the option.

Test it

Prompt
Using Composio, list the five most recent emails in my Gmail inbox
and my next three calendar events. Do not send, edit or delete anything.

Then give it a job

Prompt
Read the latest email from [client name]. Draft a reply and show it to me.
Once I approve, send it, add a meeting to my calendar, update their record
in my CRM, and post a two-line summary to the #daily-updates Slack channel.
Tip

Keep approvals on for the first two weeks. Once a workflow runs cleanly five times in a row, loosen it.

03

Set up Apify

Apify turns websites and social platforms into structured data, so Claude can find people who are talking about the problem you solve.

Connect it

  1. Create or log in to your account. Apify
    apify.com
  2. In Claude, open Settings, then Connectors, and search for Apify. Click Connect and sign in.
  3. If it is not listed, use Add custom connector and paste the Apify MCP server URL. Apify MCP server
    mcp.apify.com
  4. Open the Apify Store and pick the Actors you need. Good starting points are a LinkedIn post search Actor, a LinkedIn profile Actor and an Instagram hashtag or comment Actor.
  5. Check each Actor's pricing and input fields before you let Claude run it.

Test it

Prompt
Using Apify, find a LinkedIn posts Actor. Run it for the keyword
"[problem your offer solves]" and limit it to 10 results. Return the
author name, headline, post text and post URL as a table.
Warning

Always set a result limit in the prompt. An open-ended scrape can burn through your Apify credits in one run. Also respect each platform's terms and only collect public data.

04

Set up Clay

Clay enriches raw leads and reacts to signals like a funding round, a job post or a tool change, so your outreach lands when the timing is right.

Connect it

  1. Create or log in to your account. Clay
    clay.com
  2. Create a workspace and one table. Add the columns Name, Company, LinkedIn URL and Email.
  3. In Claude, open Settings, then Connectors, and search for Clay. Click Connect.
  4. When the Clay window opens, choose the workspace you want Claude to use and approve access.
  5. In Clay, set up the signals you care about, such as new funding, new job postings for a role you serve, or a change in the tools a company uses.
  6. Decide your trigger rule in plain words. Example: "When a company posts a job for an operations manager, enrich the contact and draft a message."

Test it

Prompt
Using Clay, show me the current workspace and list the contacts in my
leads table. Pick one contact and tell me what data points are missing.
Do not run any enrichment yet.
Note

Enrichment spends Clay credits. Run it on one lead first, check the quality, then scale to a batch.

05

Set up Fathom

Fathom records every sales call and turns it into notes, so Claude can write the follow-up before you close the laptop.

Connect it

  1. Create or log in to your account. Fathom
    fathom.video
  2. Connect your calendar inside Fathom so it knows which meetings to join.
  3. Connect your video platform (Zoom, Google Meet or Microsoft Teams) and approve the recorder permissions.
  4. In Fathom settings, switch on automatic recording for external meetings.
  5. In Claude, open Settings, then Connectors, and search for Fathom. Click Connect and sign in. If it is not listed, copy the connector URL from Fathom's help centre and use Add custom connector.
  6. Hold one real call, or a short test call with a colleague, so there is a recording to work with.

Test it

Prompt
Using Fathom, open my most recent call. Write a follow-up email to the
prospect that covers what we agreed, plus a task list with owners and
due dates. Show both to me. Do not send anything.
Important

Tell people they are being recorded. Many regions require consent, so add a line to your calendar invite.

06

Set up Higgsfield

Higgsfield gives Claude a production studio for video, images and platform cuts, from one reel idea.

Connect it

  1. Create or log in to your account and check that you have generation credits. Higgsfield
    higgsfield.ai
  2. In Claude, open Settings, then Connectors, and search for Higgsfield. Click Connect and approve the sign-in.
  3. If it is not listed, copy the connector URL from Higgsfield's documentation and use Add custom connector.
  4. Open a new chat and ask Claude to check your credit balance before generating anything.
  5. Write down your brand rules once (colours, tone, on-screen text style) so you can paste them into every request.

Test it

Prompt
Using Higgsfield, check my credit balance first. Then take this reel idea:
"[one-sentence idea]". Create one 9:16 video, one thumbnail, and a
reframed cut for each platform I post on. Use these brand rules: [paste].
Tip

Generate one clip before you request a batch. Video credits go fast, and a single test shows you whether the style matches your brand.

07

Chain all five

Each connector is useful alone. The real value shows up when one prompt moves work from one tool to the next.

How the pieces hand off

Run your first chain

  1. Confirm all five connectors are switched on in the current chat.
  2. Paste the prompt below and replace the brackets with your own details.
  3. Read the draft output at each checkpoint. Approve or correct before Claude moves on.
  4. Save the version that works as a Claude Project instruction so you can rerun it weekly.
Prompt
Run this workflow and stop for my approval after each stage.

1. Apify: find 10 recent LinkedIn posts about "[problem]".
2. Clay: enrich the authors and flag any with a hiring or funding signal.
3. Composio: draft a short personal email for each flagged lead in Gmail
   (drafts only, do not send) and log each lead in my CRM.
4. Fathom: summarise my last sales call and list any objection that
   came up more than once.
5. Higgsfield: turn the top objection into one reel idea, then make a
   9:16 video and a thumbnail.

Finish with a Slack summary in #daily-updates.
Important

Keep "drafts only" in the prompt until you trust the output. Sending is the one action you cannot take back.

Troubleshooting

Questions and fixes

Do I need all five connectors?

No. Each one works alone. Start with the tool that removes your biggest manual task, then add the rest as you need them.

The connector shows as connected but returns nothing

Check two things. First, confirm the connector is switched on for the current chat in the tools menu. Second, re-authorise the account and make sure you granted the permission the task needs.

The sign-in window does not open

Allow pop-ups for Claude in your browser, then click Connect again. If it still fails, try a private window with no extensions.

A tool is not in the Browse connectors list

Use Add custom connector and paste the remote server URL from that tool's documentation. Search the tool's help centre for "MCP" to find it.

Can Claude send or change things without asking?

Claude asks for approval on actions by default. Keep that setting on while you test, and begin every connector with read-only prompts.

Credits ran out faster than expected

Add a result limit to every scrape and a single-item test to every enrichment or video request. Check each tool's usage page after your first run.
