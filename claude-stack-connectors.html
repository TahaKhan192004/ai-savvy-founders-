Overview

What this SOP covers

Used on its own, Claude is a very smart notepad. You type, it answers, you copy the answer somewhere else and do the actual work yourself. Connect it to one outside tool and it starts saving data, publishing pages and sending emails.

Quick answer

The Claude Stack is a set of five tools (Composio, Vercel, Supabase, Clay and Resend) that you connect to Claude through MCP. MCP is a plug that lets Claude reach into another app with your permission. You do not need all five. Pick the tool that matches the job you are most tired of doing by hand and set that one up first.

Purpose

Connect Claude to one or more outside tools so it completes work inside your apps instead of handing you text to copy.

Who this is for

Founders and operators who already use Claude and want it to act on their behalf. No developer is needed.

01

Prepare Claude for connectors

Every tool in this SOP connects to Claude through MCP. The setup path depends on where you use Claude.

Setup

  1. Decide where you work: Claude.ai or the Claude desktop app, or Claude Code.
  2. In Claude.ai or the desktop app, open Settings, then Connectors. Tools listed in the directory connect with one click.
  3. For tools that are not in the directory, click Add custom connector, paste the tool's URL and sign in.
  4. In Claude Code, add each tool with one command in your terminal. Then type /mcp inside Claude Code and sign in.
  5. Check your plan. A paid Claude plan (Pro or above) makes this much easier. The free plan allows only one custom connector at a time.
  6. Choose a single tool from the steps below and set up that one first.

Note

Menu names change often in all of these apps. If a button has moved, search the tool's docs for "MCP" to find the current version of these steps.

02

Composio: connect Claude to 250+ apps

Claude can work inside Gmail, Google Sheets, Slack, Notion, HubSpot, Calendly, Asana and hundreds more, all through one connection. You do not need Zapier or a developer to wire anything together.

Setup

  1. Create a free account at Composio. Open Composiocomposio.dev
  2. In your Composio dashboard, find your MCP server URL. It is on the onboarding screen and under the MCP or Connect section.
  3. In Claude, go to Settings, then Connectors, then Add custom connector. Name it Composio and paste the URL.
  4. Start a chat and ask Claude to do something in an app, for example "check my Google Calendar for tomorrow".
  5. The first time you use each app, Composio gives you a link to log in to it. Click the link and approve access. Each app only needs this once.
  6. In Claude Code, copy the ready-made command from Composio's setup page and run it. Then type /mcp to finish signing in.

Use it for

  • Pull this week's sales calls from your calendar and draft a prep note for each one in Notion.
  • Read new form submissions in Google Sheets and post a summary to your team's Slack channel.
  • Find every email from a client in the last 30 days and turn it into a status update.
  • Create Asana tasks straight from a meeting transcript, with owners and due dates.

First prompt to try

Prompt

Look at my Google Calendar for the next 7 days. For every call with someone outside my company, find our last email thread in Gmail and give me a three-line brief on where we left things.

Warning

Composio can act on your accounts, so read the approval screens before you click through. Start by asking Claude to read and summarise. Move to "send" or "create" only once you trust what it is doing.

Note

Composio has a free tier. Paid plans change often, so check composio.dev/pricing.

03

Vercel: put what Claude builds on the internet

Claude writes the code for a dashboard, an internal tool or a landing page. Vercel turns it into a real link you can open on your phone and share with your team.

Setup

  1. Create a free account at Vercel. Signing up with GitHub makes later steps easier. Open Vercelvercel.com
  2. In Claude.ai or the desktop app, go to Settings, then Connectors, then Add custom connector. Name it Vercel and use this URL:
    URL
    https://mcp.vercel.com
  3. Sign in to Vercel when the window pops up and approve access.
  4. In Claude Code, run this command, then type /mcp and sign in:
    bash
    claude mcp add vercel --transport http https://mcp.vercel.com
  5. In Claude Code, ask Claude to "deploy this to Vercel". It uses Vercel's own command-line tool to ship the project. The connector lets it check whether the deploy worked and read the error logs if it did not.

Use it for

  • A private dashboard that shows your leads, revenue or content stats in one place.
  • A simple landing page or waitlist page for an offer you are testing this week.
  • An internal tool for your team, like a client onboarding checklist or a pricing calculator.
  • A visibility tracker that shows which of your pages and posts are getting traffic, on one screen you can open from your phone.

First prompt to try

Prompt

Build me a one-page site for my [offer name] waitlist with a headline, three short benefit sections and an email signup box. Then deploy it to Vercel and give me the link.

Important

Vercel's free Hobby plan is meant for personal, non-commercial projects. Once something is earning money or used by clients, Vercel expects you to be on the Pro plan.

Tip

The first build is the slow part. After that, every change is "fix this and redeploy".

04

Supabase: give Claude a memory

Supabase is a database Claude can save things into and read from later. Every lead, post, client note or number you track stays put after you close the chat, and the apps you build on Vercel can use it too.

Setup

  1. Create a free account at Supabase and click New project. Give it a name and save the database password somewhere safe. Open Supabasesupabase.com
  2. Inside your project, open the MCP connection tab in the Connect menu. It builds a custom URL for you and has a switch for read-only mode. Turn read-only on while you are learning.
  3. In Claude, go to Settings, then Connectors, and search the directory for Supabase.
  4. If Supabase is not in the directory, click Add custom connector and paste the URL from step b. The general URL is:
    URL
    https://mcp.supabase.com/mcp
  5. Sign in to Supabase when prompted and pick the organisation you want Claude to see.
  6. In Claude Code, run this command, then type /mcp and sign in:
    bash
    claude mcp add --transport http supabase https://mcp.supabase.com/mcp

Use it for

  • A lead tracker where Claude logs every new contact, where they came from and what you last said to them.
  • A content library that stores every post you publish with its performance, so Claude can tell you what is working.
  • The data behind your Vercel dashboard, so the numbers update without you touching a spreadsheet.
  • A log of client wins and testimonials you can pull from whenever you write a sales page.

First prompt to try

Prompt

Create a table in my Supabase project called leads with columns for name, email, source, status and notes. Then add these five people to it: [paste your list].

Note

This prompt needs read-only switched off. Turn it back on afterwards if you like.

Warning

Supabase's connector can create, change and delete data. Keep it pointed at one project. Do not give it write access to a database that real customers depend on until you are comfortable.

Note

Free projects pause after about a week without activity. Click "restore" to wake them up.

05

Clay: let Claude research your leads properly

Clay finds and enriches people and companies. Give Claude a name, a company or a type of buyer, and Clay fills in their role, company size, recent news and verified contact details. Claude then works from real facts instead of guessing.

Setup

  1. Create an account at Clay. Open Clayclay.com
  2. In Claude, go to Settings, then Connectors, and find Clay in the connector directory. Click Connect.
  3. Sign in to Clay and approve access. On a Claude Team or Enterprise plan, your admin may need to switch the Clay connector on first.
  4. In Claude Code, check clay.com/mcp for the current server URL and add it the same way as the other tools. Then type /mcp to sign in.

Use it for

  • Research everyone who booked a call this week before you get on with them.
  • Turn a list of 200 names from a webinar or challenge into a ranked list of your best-fit buyers.
  • Find decision-makers at companies that match your ideal client, with a reason to reach out to each one.
  • Pull a prospect's role, company size and a recent announcement before a discovery call, so you open with something specific to them.

First prompt to try

Prompt

Using Clay, research these 10 people: [paste names and companies]. For each one, tell me their role, company size and anything recent that would make a good opening line. Then rank them by how well they fit [describe your ideal client].

Important

Searching for people and companies is free. Enrichment uses Clay credits, the same as inside Clay itself. A single research request can use anywhere from about 20 to 100 credits, so start with a list of 10 before you run 200.

Tip

New accounts have been given free credits on first connect. Check what you have before you buy more.

06

Resend: let Claude send real emails

Claude can send emails from your own domain to real people: follow-ups, onboarding emails, a personal note to every new lead. It writes them and sends them.

Setup

  1. Create a free account at Resend. Open Resendresend.com
  2. Add and verify your domain. Resend gives you a few DNS records to copy into wherever your domain lives, such as GoDaddy, Namecheap or Cloudflare. Use a subdomain like send.yourbusiness.com so your main domain's reputation stays protected.
  3. Create an API key under API Keys. Copy it somewhere safe, because Resend only shows it once.
  4. In Claude Code, run this command with your real key, then restart Claude Code:
    bash
    claude mcp add resend -e RESEND_API_KEY=re_yourkeyhere -- npx -y resend-mcp
  5. In Claude.ai or the desktop app, add Resend's hosted connector as a custom connector and sign in:
    URL
    https://mcp.resend.com/mcp
  6. If the hosted connector is not working for you, follow the desktop config-file method in Resend's docs. Resend MCP server docsresend.com/docs/mcp-server

Use it for

  • A personal follow-up to everyone who attended your workshop, referencing what they asked in the chat.
  • Onboarding emails to a new client the minute they sign.
  • Outreach to the leads Clay researched for you, each with its own opening line.
  • A weekly report emailed to you or your team with the numbers from Supabase.
  • A first reply to every new waitlist signup, sent from your own domain once you have approved the draft.

First prompt to try

Prompt

Write a short, warm follow-up email to [name] thanking them for [what happened]. Show me the draft first. Once I approve it, send it from hello@send.yourbusiness.com using Resend.

Warning

Always ask Claude to show you the draft before it sends, at least until you have seen ten in a row you would send yourself.

Important

Until your domain is verified, you can only send test emails to your own address. Only email people who would reasonably expect to hear from you, and include a way to opt out of anything that looks like marketing.

07

Choose which tool to start with

Set up one tool this week. Match it to the job that costs you the most time right now.

  1. If you spend your day copying things between apps, start with Composio. It pays off the fastest.
  2. If you keep asking Claude to build things you then cannot use, start with Vercel. Add Supabase the moment you want that build to remember anything.
  3. If you sell high-ticket and your calendar has strangers on it, start with Clay. Add Resend when you are ready for Claude to handle the follow-up too.
08

Run the five tools together

Each tool is useful on its own. Connected, they become a small system. This is the full sequence once everything is set up.

  1. Clay researches a new lead and returns their role, company and a recent detail worth mentioning.
  2. Claude saves what it found to Supabase.
  3. Resend sends a personal email that opens with a line from that research.
  4. Composio creates a task in your project manager to follow up in three days.
  5. A dashboard on Vercel shows you the whole pipeline on your phone.

Tip

None of this needs a developer. It needs you to set up one plug at a time.

FAQs

Frequently asked questions

What is MCP and do I need to understand it?

MCP is a plug that lets Claude reach into another app with your permission. You do not need to understand how it works to use it.

Do I need to set up all five tools?

No. Pick the one that matches the job you are most tired of doing by hand, set it up this week and come back for the next one later.

Can I connect these tools on the free Claude plan?

The free plan allows one custom connector at a time. A paid plan (Pro or above) makes setting up several tools much easier.

Do I need a developer to build this stack?

No. Each tool is set up with a sign-in or a single command, one at a time.

Is it safe to let Claude send emails or change data?

Start with read-only access and draft-first sending. Ask Claude to show every email before it goes out, keep Supabase in read-only mode while you learn, and read each approval screen before you click through.

Which tool should I set up first?

Start with Composio if you copy data between apps all day, Vercel if you want Claude's builds online, or Clay if you sell high-ticket and your calendar has strangers on it. Step 7 has the full guide.
