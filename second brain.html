Start here

Save every useful chat to one private repo

Setup takes about 30 minutes, once. After that you type one of three commands in any chat: save to repo, show [date] or open [date] [file].

Your Claude and ChatGPT chats end up as tidy files in a private GitHub repo called team-brain, organised by month and day. Anything saved in one app can be opened in the other.

Before you start

  • One GitHub account, which owns the repo. Both Claude and ChatGPT connect to this same account.
  • A paid Claude plan (Pro or Max). On a Team plan, the organization owner adds the connector first.
  • A ChatGPT plan that shows GitHub under Settings → Apps. On some plans it only appears in Deep Research or Agent mode, so check before you start.
  • A computer with a browser. Do the setup on the web. The phone apps then work automatically.

Step 1 · 2 minutes

Create the repo

Create the repo by hand. Claude and ChatGPT are only given access to repos that already exist, so they can't create this one for you.

  1. Go to github.com/new and sign in.
  2. Under Repository name, type team-brain.
  3. Select Private.
  4. Tick Add a README file.
  5. Click Create repository.
Result
You have an empty private repo at github.com/<your-username>/team-brain.

Step 2 · 5 minutes

Connect GitHub to Claude

Use Claude's built-in GitHub connector. You sign in to GitHub, and there's no URL or key to paste.

  1. Open claude.ai on a computer.
  2. Go to Settings → Connectors and search for GitHub.
  3. Click Connect and sign in with the GitHub account from Step 1.
  4. When GitHub asks which repositories to allow, choose Only select repositories → team-brain, then approve.
Result
GitHub shows as connected under Settings → Connectors, and it also works in the Claude phone app.
If Step 4's test fails

If the test shows Claude can read the repo but can't create files, the built-in connector on your plan is read-only. Add GitHub's own connector instead. It still uses sign-in, with no keys.

  1. Go to Settings → Connectors → + → Add custom connector.
  2. Enter the name GitHub and the URL https://api.githubcopilot.com/mcp.
  3. Click Add → Connect and sign in. (Reference)

Step 3 · 5 minutes

Connect GitHub to ChatGPT

ChatGPT uses its own official GitHub app (OpenAI guide).

  1. Open chatgpt.com on a computer.
  2. Go to Settings → Apps.
  3. Find GitHub and click Connect.
  4. GitHub opens. Sign in with the same GitHub account from Step 1.
  5. When GitHub asks which repositories to allow, choose Only select repositories → team-brain, then click Install & Authorize.
  6. Back in ChatGPT, wait about 5 minutes. A new repo can take that long to appear.
Result
GitHub shows as connected under Settings → Apps.

Step 4 · 5 minutes

Test both connections

Open a new chat in Claude and paste this prompt. Replace <your-username> with your GitHub username.

Prompt · Claude
Using GitHub, open the repo <your-username>/team-brain.
Create the file test/hello.md with this text: "Saved from Claude."
Then add a second line to the same file: "Update works."
Reply with the link to the file.

Then open a new ChatGPT chat and paste the same prompt with "Claude" changed to "ChatGPT" and the path changed to test/hello-chatgpt.md.

Pass: both files appear on GitHub, each with two lines. Fail: see If something goes wrong. Once both pass, delete the test folder on GitHub.

Step 5 · 2 minutes

Create MEMORY.md, the rulebook

MEMORY.md sits in the main folder of the repo and holds the folder rules. Both apps read it, so they save things the same way. Paste this into Claude once, exactly as written:

Prompt · Claude
Using GitHub, create the file MEMORY.md in <your-username>/team-brain with exactly this content:

# Team Brain: rules

## Folder structure
team-brain/
  MEMORY.md                  <- this file
  YYYY-MM/                   <- one folder per month, e.g. 2026-10
    DD/                      <- one folder per day, e.g. 27
      chat-name.md           <- one file per saved chat

Example: 2026-10/27/cohort-promo-reel.md

## File names
- Use the chat's title in lowercase, words joined with hyphens.
- If a file with that name already exists that day from a DIFFERENT chat, add -2, -3.
- Saving the SAME chat again updates its existing file.

## What goes in each file
# <Chat title>
Date: YYYY-MM-DD | Saved by: <name> | Tool: Claude or ChatGPT
## Summary
## Full context
Everything discussed, in order, with all details needed to continue the work.
## Final outputs
Every final version in full: copy, captions, scripts, prompts, code, lists.
## Decisions
## Links and files
## Next steps

## Commands
- save to repo -> save this chat to YYYY-MM/DD/chat-name.md (today's date)
- show <date> -> list all files in that day's folder
- open <date> <file name> -> read that file and use it in this chat
- show <month> -> list all day folders and files in that month

## Privacy filter (check before every save)
Remove these and write [removed] in their place:
- Client names, emails, phone numbers, addresses, contracts, prices and invoices
- Passwords, API keys, tokens, login links, bank or card details
If a chat is mostly client-confidential, don't save it. Tell the user instead.
Result
MEMORY.md appears in the repo. To change a rule later, edit this file on GitHub.

Step 6 · 5 minutes

Teach both apps the commands

Paste the same text into the settings of both apps. They then follow it in every new chat, on computer and phone. Replace the two <...> parts first.

Settings text · both apps
TEAM BRAIN: my GitHub repo <your-username>/team-brain stores my saved chats.
The rules are in MEMORY.md in that repo. My name: <your name>. Timezone: Asia/Karachi.

When I type one of these commands, do exactly this using GitHub:

"save to repo"
1. Use today's date. Path: YYYY-MM/DD/chat-name.md
   (chat-name = this chat's title, lowercase, words joined with hyphens).
2. If this chat was already saved, update that same file. Do not create a new one.
3. Fill the file using the template in MEMORY.md: summary, full context,
   every final output in full, decisions, links, next steps.
4. Reply with the file path and the link.

"show <date>" (example: show 27 Oct)
List every file in that day's folder. If there are none, say so.

"show <month>" (example: show Oct)
List each day folder in that month and the files inside it.

"open <date> <file>" (example: open 27 Oct cohort-promo-reel)
Read that file, give me a 3-line summary, and use it as background for the rest of this chat.

If I don't give a year, use the current year.
Only save when I ask.
PRIVACY FILTER: before every save, remove client names, contact details,
contracts and prices, and any passwords, API keys, tokens or bank/card details.
Write [removed] in their place. If a chat is mostly client-confidential, don't save it. Tell me instead.

Where to paste it:

AppWhereField
ClaudeSettings → ProfilePersonal preferences (what Claude should consider in responses)
ChatGPTSettings → Personalization → Custom instructionsThe instructions box. Save, and keep custom instructions turned on

After saving, start a new chat. Chats that were already open won't pick up the change.

Also save it to each app's memory

In Claude and in ChatGPT, open a new chat and send this, with the full text from above pasted in:

Prompt · both apps
Save the following to your memory permanently, exactly as written, and follow it in every future chat:

<paste the full TEAM BRAIN text from above>

The app should confirm that memory was updated. If nothing happens, turn memory on first. In Claude it's under Settings → Capabilities. In ChatGPT it's under Settings → Personalization → Memory. Keep the settings text from above as well: settings are read in every chat, while memory is a backup.

Step 7 · 15 minutes

Keep a local folder in sync with Claude Code

This puts the repo on your computer as a normal folder. Files you add or edit there go up to GitHub, and chats saved from Claude or ChatGPT come down into it. Repeat this on each computer.

  1. Install Claude Code from claude.com/claude-code. It's included with Claude Pro and Max.
  2. Open Terminal (Mac) or PowerShell (Windows), type claude, press Enter, and sign in.
  3. Paste this prompt, replacing <your-username> first:
Prompt · Claude Code
Set up my team brain folder on this computer:
1. Check that git and the GitHub CLI (gh) are installed. Install them if missing,
   then log me in to GitHub with "gh auth login" (I'll finish the sign-in in the browser).
2. Clone https://github.com/<your-username>/team-brain into my Documents folder.
3. Add a .gitignore that blocks: .env, *.key, *.pem, any file with "secret",
   "password" or "credential" in its name, and a folder called private/.
4. Set up automatic sync every 5 minutes that runs even when you are closed:
   pull new changes, then commit and push my local changes with the message "auto-sync".
   Use launchd on Mac or Task Scheduler on Windows.
   If two edits clash, keep both versions and tell me. Never force-push.
5. Privacy filter: before each auto-commit, scan the changed files for passwords,
   API keys, tokens, card numbers and lines marked CONFIDENTIAL. If any are found,
   skip that commit and show me a notification naming the file.
6. Do one test sync and tell me the folder path.
Result
A team-brain folder in Documents that stays in step with GitHub every 5 minutes. Keep anything client-private in the private/ folder. It stays on your computer and is never uploaded.

Type the command as a normal message, in any chat, in either app.

Tips

  • Give the chat a clear title before saving. The title becomes the file name.
  • Save at the end of a useful chat, and again after any big change.
  • To continue work from another day or app, start a new chat and type open <date> <file> first. It works across apps: something saved in ChatGPT can be opened in Claude.
  • The first time you use a command, the app may ask permission to use GitHub. Choose Always allow if it's offered.

Extras

Good to know

Adding teammates

Add each teammate as a collaborator on GitHub. Don't share one login.

  1. On GitHub, open team-brain → Settings → Collaborators → Add people.
  2. Enter the teammate's GitHub username and send the invite.
  3. The teammate accepts the invite from their email or GitHub notifications.
  4. The teammate does Steps 2, 3, 6 and 7 with their own Claude and ChatGPT accounts and their own computer, using their own name in Step 6.

Everyone then saves to and opens from the same repo, so a chat Umaima saves can be opened by Taha, and the other way round.

Phone access

Once a connection is set up on the computer, it also works in the Claude and ChatGPT phone apps. The same commands work there too. New connections can only be added from the computer.

Other AI tools can use the same memory

Any assistant that connects to this GitHub account can read the whole repo, including Codex, Claude Code, Cursor and others. Point it at <your-username>/team-brain and tell it to read MEMORY.md first. It then follows the same folders and can open any saved chat.

This also means

Anything saved in the repo can be seen by every person and every tool with access to it. Keep passwords, API keys and private client details out. To remove a tool's access, go to GitHub → Settings → Applications and revoke it.
