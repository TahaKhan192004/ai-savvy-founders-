Purpose

What this does

This SOP takes you from nothing to a WhatsApp AI employee that answers customer messages automatically. You connect a WhatsApp number to Kapso, connect Claude Code to Kapso, and let Claude build the agent while you approve each step.

You talk to Claude Code in plain language and paste in nine ready-made prompts. By the end you will have:

  • A WhatsApp number connected to Kapso
  • Claude Code connected to Kapso through MCP
  • An AI agent built for one specific business job
  • External tools and business systems connected
  • A deployed workflow that replies to incoming messages

Who this is for

  • Founders who get customer messages on WhatsApp
  • Teams automating support, bookings or lead qualification
  • Beginners who want to build without the terminal

Tools needed

  • Kapso account
  • Claude Code (web or desktop)
  • A WhatsApp number customers will message
  • A second phone for testing

Part 1 · Setup

Open Claude Code

Choose one way to talk to Claude Code. Both let you give instructions in plain language, so no terminal commands are needed.

Option A: Claude Code on the web

  1. Visit claude.ai/code and sign in.
  2. Connect your GitHub account if asked.
  3. Select the repository you want to work on.
  4. Start a new coding session.

Option B: Claude Desktop

  1. Download Claude Desktop and sign in.
  2. Open the Code tab.
  3. Select a project folder.
  4. Start a new coding session.
Tip
Pick a fresh, empty project folder for this build. It keeps the agent's files and instructions in one place.
02

Part 2 · WhatsApp number

Create your Kapso account

  1. Visit app.kapso.ai.
  2. Create your account.
  3. Complete the onboarding process.
  4. Create or open your Kapso project.
03

Part 2 · WhatsApp number

Connect your WhatsApp number

Pick one of two routes.

Option A: Kapso-provided number

  1. Open your Kapso project.
  2. Start the WhatsApp number setup.
  3. Select the Kapso-provided number option.
  4. Follow the onboarding instructions.

Option B: Your existing business number

  1. Select the option to connect your own number.
  2. Follow Meta's WhatsApp Business onboarding.
  3. Authorize the required permissions.
  4. Complete the connection.
Tip
For your first experiment, start with a Kapso-provided test number if one is available. You can move to your real business number once the agent works.

Part 3 · Connect Claude to Kapso

Connect Claude Code to Kapso

This step gives Claude access to your Kapso project through Kapso's official MCP integration. MCP is how Claude talks to outside tools and services.

  1. Open your Claude Code session.
  2. Copy and paste Prompt 1 below.
  3. Follow Claude's instructions whenever it asks for authorization.
  4. Enter any API key through the secure configuration flow Claude points you to, never in the chat.

Prompt 1: Connect Kapso

Prompt
Set up WhatsApp for this project with Kapso.

Follow the official setup instructions here:
https://kapso.com/whatsapp-claude-code

Read the instructions and the relevant Kapso documentation.

Help me connect the Kapso MCP server to this Claude Code project.

Ask me before creating any API keys or making changes to my Kapso account.

Guide me through the authentication process. If you need an API key, tell me exactly where to find it and let me enter it through the appropriate secure configuration flow.

Do not expose or print my credentials.

After setup, verify that the connection is working.

Claude will read Kapso's setup instructions, configure the MCP connection, ask for the authentication details, and check that the integration is available.

Part 5 · Build the agent

Configure the agent's instructions

The agent needs clear instructions about its role, responsibilities and limits. Paste Prompt 5, then read the system prompt Claude writes before it is applied.

Prompt 5: Configure Agent Instructions

Prompt
Create a system prompt for my WhatsApp AI agent.

Use the following structure:

BUSINESS INFORMATION:
- Business name
- Business description
- Products and services
- Business hours
- Contact information

AGENT RESPONSIBILITIES:
- Understand incoming customer messages.
- Identify customer requirements.
- Answer questions using business information.
- Ask relevant follow-up questions.
- Use connected tools when necessary.
- Complete authorized business actions.
- Escalate situations requiring human assistance.

COMMUNICATION STYLE:
- Friendly and professional.
- Short, natural WhatsApp messages.
- Ask one question at a time.
- Avoid robotic language.

IMPORTANT RULES:
- Never invent business information.
- Never claim an action was completed unless the relevant tool confirms success.
- Never expose private customer information.
- Never perform unauthorized actions.
- Escalate uncertain situations.

Use my actual business information and tailor the instructions to the agent's purpose.

Show me the final system prompt before implementing it.

Before you go live

Important things to remember

  1. MCP is not the deployed agent. MCP connects Claude Code to Kapso during development. Your live agent needs a deployed workflow or other running runtime.
  2. WhatsApp has messaging restrictions. There is a 24-hour customer-service window. Approved templates may be required for business-initiated messages outside it.
  3. There are usage costs. Kapso may offer free usage, but Meta messaging fees, AI model usage and external services can add charges.
  4. Protect customer information. Use secure credentials, restrict permissions and follow applicable privacy requirements.

FAQs

Questions answered

Do I need to use the terminal?

No. You work through Claude Code's chat interface and copy-and-paste prompts. No terminal commands are required.

Is the MCP connection the deployed agent?

No. MCP connects Claude Code to Kapso while you build. Your live agent needs a deployed Kapso Workflow or another running runtime to process messages continuously.

Can the agent message customers any time?

No. WhatsApp has a 24-hour customer-service window. Approved message templates may be required for business-initiated messages outside that window.

What does it cost?

Kapso may offer free usage allowances, but Meta messaging fees, AI model usage and any external services you connect can add charges.

How do I keep customer data safe?

Use secure credentials, restrict permissions, never paste keys into the chat, and follow the privacy requirements that apply to your business.
