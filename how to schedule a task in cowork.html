Standard Operating Procedure

Schedule a Cowork task that repurposes your content for you

Set up a recurring task in Claude Cowork that picks up every new transcript and turns it into a reel script, a LinkedIn post, a Facebook post, and a carousel. You record. It publishes-ready.

Purpose

Every voice note, YouTube video, or masterclass you record contains a week of content. The bottleneck is not the recording. It is sitting down afterward to slice it into posts. This SOP moves that slicing to a scheduled Cowork task that runs on its own, without you opening a chat.

Who this is for: founders who already record content regularly and have a working repurposing prompt or skill. If you have never repurposed a transcript with Claude before, run one manually first so you know what good output looks like.

01

Confirm prerequisites

  • a.Install the Claude desktop app from claude.com/download and sign in.
  • b.Confirm you are on a paid Claude plan. Scheduled tasks are part of Cowork, which is not on the free tier.
  • c.Open the Cowork tab in the desktop app and confirm it loads.
  • d.If you use a repurposing skill (for example a content repurposing skill that outputs four formats), confirm it is installed and Cowork can see it.
02

Create your repurposing folders

The task needs one place to look for new material and one place to drop finished content.

  • a.Create a folder named Transcripts Inbox on your computer or in a synced drive. This is where you save every new transcript, voice note export, or YouTube transcript.
  • b.Create a second folder named Content Outputs. The task will save the finished pieces here, one subfolder per transcript.
  • c.In Cowork, grant access to both folders when prompted, or add them through the folder picker in a Cowork session.
Note

Keep the inbox folder clean. Move processed transcripts to an archive subfolder, or instruct the task to do it. Otherwise the same transcript gets repurposed twice.

03

Test the repurposing prompt manually

Never schedule a prompt you have not run once by hand. Open a new Cowork task, drop one transcript into the inbox folder, and run this prompt:

PromptCheck the "Transcripts Inbox" folder for any transcript files that do not have a matching subfolder in "Content Outputs". For each new transcript, use my content repurposing skill to create: 1. A timed reel script with on-screen text cues 2. A LinkedIn post 3. A Facebook post 4. A carousel (slide by slide) with its caption Each piece must use a different angle from the transcript. Save all four pieces as separate files in a new subfolder inside "Content Outputs", named after the transcript and today's date. Then move the processed transcript into "Transcripts Inbox/Archive". If there are no new transcripts, stop and do nothing.
  • a.Review the four output files against your voice and brand rules.
  • b.Adjust the prompt wording until one manual run produces content you would actually post.
  • c.Save the final prompt somewhere you can paste from. This exact text becomes the scheduled task instructions.
Important

Scheduled runs do not pause to ask you questions the way a live session can. The prompt has to contain every rule up front: folder names, formats, angles, and what to do when there is nothing new.

04

Open the Scheduled tasks page

There are two doors into scheduling. Pick the one that fits today.

  • a.Sidebar route: in the Cowork tab, click Scheduled in the left sidebar. This opens the Scheduled tasks page where every task lives.
  • b.Command route: inside any Cowork task, type /schedule to start scheduling from where you are.
05

Create the scheduled task

  • a.On the Scheduled tasks page, click New task in the upper right.
  • b.Choose Create with Claude. Claude asks a few multiple choice questions, then drafts the task for you. Paste your tested prompt from Step 3 when asked what the task should do.
  • c.Or choose Set up manually and fill the fields yourself: a name you will recognize later (for example Weekly Content Repurposing), a short description, and the full instructions.
Tip

Name tasks by outcome, not by tool. "Weekly Content Repurposing" tells you what you get. "Cowork automation 3" tells you nothing in six months.

06

Set the cadence

Match the schedule to your recording rhythm, not to what sounds impressive.

Your habitRecommended scheduleWhy
Daily voice notesEvery weekday, early morningFresh content is waiting before you start work
One long video per weekWeekly, the morning after your usual recording dayOne run handles the whole batch
Irregular recordingTwice weeklyThe task exits quietly when the inbox is empty, so extra runs cost little
07

Confirm and schedule

  • a.Review the summary Claude shows: the task name, the schedule it will follow, and what the task does.
  • b.Click Schedule to confirm. The task appears on the Scheduled tasks page.
  • c.Scheduled tasks run remotely, so your computer does not need to be awake and the desktop app does not need to be open at run time.
08

Verify the first run

  • a.Drop one fresh transcript into Transcripts Inbox before the first scheduled run.
  • b.After the run time passes, open the Scheduled page and check the run history for the task.
  • c.Open Content Outputs and review all four pieces. Check voice, angles, and formatting against your brand rules.
  • d.If anything is off, edit the task instructions on the Scheduled page. Small wording changes fix most output drift.
Warning

Cowork tasks use more of your usage allocation than regular chat, and a broad task multiplies that. Keep the scope tight: new transcripts only, four pieces per transcript, stop when the inbox is empty.

FAQs

Does my computer need to stay on?

No. Scheduled tasks run remotely, so they do not need your machine awake or the desktop app open. If your transcripts live in a local folder, keep that folder in a synced drive so the run can reach the latest files.

Can the scheduled run use my skills and connectors?

Yes. Each run uses the same connectors, plugins, and file access you have already set up in Cowork. If your repurposing skill works in a live session, it works in the scheduled run.

How do I pause or edit the task later?

Open the Scheduled page from the Cowork sidebar. Every task can be viewed, edited, paused, or deleted from there.

Can I run it on demand between scheduled runs?

Yes. Open the task from the Scheduled page and trigger a run manually whenever you drop in an urgent transcript.
