Purpose

Connect GoHighLevel's MCP server to Claude Desktop Co-Work so you can query, automate, and manage your CRM directly from Claude using scheduled agents.

Who This Is For

Founders and operators using GoHighLevel as their CRM who want AI-driven daily operations, lead monitoring, and automated follow-ups.

Tools Needed

Claude Desktop app (with Co-Work access), an active GoHighLevel account with at least one sub-account.

IMPORTANT

This SOP uses the Anthropic OAuth version of the GHL MCP endpoint. This is the version designed for Claude Desktop and is different from the Private Integration Token (PIT) flow used with Cursor, n8n, or custom agents. GoHighLevel is actively expanding the MCP's available scopes and tools, so capabilities will grow over time.

01

Open Claude Desktop Co-Work

Launch the Claude Desktop application on your computer. From the top-level navigation, click on Home, then navigate to the Co-Work tab.

This is where all your connectors, scheduled tasks, and agents live. If you have not set up Claude Co-Work before, you will see an empty workspace ready for configuration.

02

Add a custom connector

  1. Inside Co-Work, click Customize in the sidebar or top menu.
  2. Select Connectors from the customization panel.
  3. Click Add, then choose Add Custom Connector.

A form will appear asking for the connector name and the remote MCP server URL. Leave this window open for the next step.

03

Enter the MCP server URL

  1. In the Name field, type GoHighLevel MCP Server (or any name you prefer).
  2. In the Remote MCP Server field, paste the Anthropic-version endpoint URL.
  3. Click Add.

The endpoint for the Anthropic (Claude Desktop) version of the MCP server is published on the GoHighLevel marketplace documentation page. At the time of writing, use this URL:

Anthropic MCP Endpoint (Claude Desktop)
https://services.leadconnectorhq.com/mcp/anthropic/v2

You can also confirm the latest endpoint on the official documentation page:

GoHighLevel MCP Documentation
marketplace.gohighlevel.com/docs/other/mcp/

WARNING

GoHighLevel updates MCP endpoint URLs as they release new versions. Always check the official docs page linked above for the latest URL before pasting. If your connection stops working after an update, revisit this step and replace the URL.

04

Authenticate with GoHighLevel

  1. After clicking Add, Claude will prompt you to connect. Click the Connect button.
  2. A browser window will open with the GoHighLevel login page. Click Install.
  3. Enter your GoHighLevel email and password.
  4. Complete two-factor authentication if your account requires it (check your phone for the verification code).
  5. A list of your sub-accounts will appear. Select the account you want to connect to Claude.
05

Approve scopes

After selecting your sub-account, GoHighLevel will display a list of all available scopes (permissions) that the MCP connection can access. These determine what Claude can read and write inside your CRM.

Review the list and click Allow and Install to grant all scopes. The connection will install into your selected sub-account.

TIP

Grant all available scopes during setup. This gives Claude the widest range of automation capabilities. You can always adjust individual tool permissions later. If you restrict scopes now, some agents and tasks will not function when you build them.

06

Verify the connection

Once authentication completes, Claude will bring you back to the Co-Work interface.

  1. Click Customize again.
  2. Open Connectors.
  3. Confirm that GoHighLevel MCP Server appears in your connector list with a connected status.

If the connector does not appear, go back to Step 2 and repeat the process. Ensure you are using the correct (Anthropic version) endpoint URL from the GHL docs page.

07

Discover available tools

Now that the connection is live, ask Claude to audit what is available. Open a new conversation in Co-Work and send a prompt like this:

Prompt I just connected my GoHighLevel MCP. Go in and tell me what tools and capabilities you have available. Help me identify tasks and agents I can run on a schedule to optimize my CRM operations.

Claude will query the MCP server and return a categorized list of everything it can do: contact management, conversation search, calendar events, pipeline monitoring, payment lookups, social media posting, blog management, and email template creation.

TIP

Switch your model to Opus and set effort to High for this discovery step. It will give you a more thorough breakdown of available capabilities and better agent suggestions tailored to your business.

08

Build your first scheduled agent

Start with the highest-value daily task: a conversation sweep that catches unanswered messages and drafts responses for you.

  1. Tell Claude to search your GHL conversations for any unanswered messages or unread replies that came in since yesterday.
  2. Review the results. Claude will pull the actual messages and draft ready-to-send responses for each one.
  3. If you already have a morning daily brief scheduled in Co-Work, tell Claude to fold this conversation sweep into that existing task.
  4. If you do not have a daily brief yet, ask Claude to create a new scheduled task that runs this sweep every morning at 9:00 AM.
Prompt Do a sweep of my GoHighLevel conversations right now. Find any unanswered messages or unread replies. Draft a response for each one. Then fold this check into my 9:00 AM daily brief. Real conversations only.

Claude will search your conversations, identify gaps, draft responses, and then add the recurring task to your scheduled brief. Every morning at 9:00 AM, you will have drafted replies waiting for your review.

09

Create business automation agents

Once your daily sweep is working, ask Claude to suggest additional agents based on what it knows about your business and the tools available through the MCP. High-value agents to consider:

No-Show Recovery Checks calendar events for missed appointments and sends a re-booking prompt to the contact. Daily

To create each agent as a scheduled task, navigate to Scheduled Tasks inside Co-Work and either add new tasks directly or ask Claude to create them for you within the conversation.

Alternative Method

Private Integration Token (PIT) Setup

If you are connecting to the GHL MCP from tools other than Claude Desktop (Cursor, Windsurf, n8n, OpenAI Playground, or a custom LangGraph agent), you will use a Private Integration Token instead of the OAuth flow above.

  1. In GoHighLevel, go to Settings then Private Integrations.
  2. Click Create New Integration, select the scopes you need, and copy the generated token.
  3. Configure your agent or client with the standard MCP endpoint and pass the token as a Bearer header.
JSON { "mcpServers": { "ghl-mcp": { "url": "https://services.leadconnectorhq.com/mcp/", "headers": { "Authorization": "Bearer pit-YOUR-TOKEN-HERE", "locationId": "YOUR-LOCATION-ID" } } } }

The locationId header is optional. You can also pass it as part of your prompts or set it in the system prompt of your LLM node.

Frequently Asked Questions

What can the GoHighLevel MCP do inside Claude?

The GHL MCP currently supports 36 tools across contacts, conversations, calendars, opportunities, payments, social media posting, blogs, email templates, and location data. You can search, create, update, and manage records directly from Claude. It cannot yet access workflows, funnels, forms, or phone system features, but GoHighLevel is expanding scope coverage.

Do I need a Private Integration Token (PIT) for the Claude Desktop connection?

No. The Claude Desktop Co-Work connector uses the Anthropic OAuth version of the MCP endpoint. You authenticate by logging into your GoHighLevel account directly through the connection flow. PIT tokens are for direct API integrations with tools like Cursor, n8n, or custom agents.

Can my team members connect their own accounts?

Yes. Each team member can install the connector on their own Claude Desktop and connect it to the same or different GHL sub-accounts. For centralized control, consider setting up agents on one account first and distributing outputs and drafted responses to associates.

What if the MCP endpoint URL changes?

GoHighLevel updates endpoint URLs as they release new server versions. If your connection stops working, go to the GHL MCP docs page, copy the latest Anthropic endpoint URL, delete your existing connector, and re-add it with the updated URL. Your scopes and authentication will be re-established during the new connection flow.

Can I connect multiple GHL sub-accounts?

Yes. You can add multiple custom connectors inside Claude Co-Work, each pointing to a different sub-account. Name them distinctly (for example, "GHL MCP - Agency" and "GHL MCP - Client A") so Claude can differentiate between them when running agents.

Troubleshooting

Connection fails during authentication

Confirm you are using the Anthropic-version endpoint URL, not the generic MCP URL. Clear your browser cache, then retry. If your GoHighLevel account has IP-based access restrictions, ensure Claude's authentication request is not being blocked.

Claude says it cannot find certain tools

Some tools require specific scopes. If you restricted scopes during setup, go back to GoHighLevel Settings, find the integration, and expand the granted scopes. Then disconnect and reconnect the MCP connector in Claude Co-Work.

Scheduled tasks are not running

Ensure Claude Desktop is running (not just the browser version) and that Co-Work scheduled tasks are enabled. Check that the task is listed under Scheduled Tasks with the correct time and recurrence. If the task references a connector that was disconnected, reconnect it first.
