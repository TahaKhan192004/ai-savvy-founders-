Before you start

What you need

You need three things, and setup takes about five minutes.

  • Claude Code installed (or Cursor, Codex or Windsurf).
  • Node.js installed, which is needed for the npx install command.
  • A project folder open, ideally the one for your website or product.

New to the terminal and coding agents? Read the free companion guide Coding for Marketers first. Our Claude Code starter guide also covers the basics.

Step 1

Install the skills

Pick one method. Method A is the fastest and needs no commands.

Method A: Ask Claude Code to install it (easiest)

  1. Open Claude Code inside your project folder.
  2. Paste this prompt:
Prompt
Clone this repo and install all the skills inside it into .claude/skills so Claude Code can use them: https://github.com/coreyhaines31/marketingskills
  1. Wait for Claude to confirm the skills are installed.
  2. Restart the Claude Code session so it loads the new skills.
Important

Name the .claude/skills folder in your prompt. When an agent installs skills for you, it can drop them into the shared .agents/skills/ folder, which Claude Code does not read.

Method B: One-line CLI install

Run this in your terminal:

Terminal
npx skills add coreyhaines31/marketingskills -a claude-code

The -a claude-code flag tells it to install for Claude Code. Variations:

Terminal
# Install only the skills you want
npx skills add coreyhaines31/marketingskills --skill cro copywriting

# See every available skill first
npx skills add coreyhaines31/marketingskills --list

Method C: Claude Code plugin

Inside an interactive Claude Code session, run:

Claude Code
/plugin marketplace add coreyhaines31/marketingskills
/plugin install marketing-skills
Note

/plugin does not work in Claude Code on the web or in GitHub Actions. Use Method A or B there.

Method D: Clone and copy manually

Terminal
git clone https://github.com/coreyhaines31/marketingskills.git
cp -r marketingskills/skills/* .claude/skills/

Method E: Claude on the web (ZIP upload)

  1. Open the latest release in the repo.
  2. Download the <name>-claude-web.zip for the skill you want. Each ZIP holds one skill.
  3. In Claude, go to Customize, then Skills, then Create skill, then Upload a skill.

Step 2

Build your product marketing context

Do this once, before anything else. The product-marketing skill is the foundation: every other skill reads its output first to learn your product, audience and positioning.

  1. In Claude Code, type this prompt:
  2. Answer Claude's questions: what you sell, who it's for, the problem you solve, your competitors and your tone of voice. If you have a live site, say "read my website first" so it fills in what it can.
  3. Claude saves the result as .agents/product-marketing.md in your project.
  4. Review the file and fix anything that sounds wrong. Every later skill uses it.
Prompt
Use the product-marketing skill to create my product marketing context.
Do not skip this

Skip this step and the other skills give generic advice. Do it well and every output sounds like your brand. Update the file whenever your offer, pricing or audience changes.

Step 3

How to use the skills

There are two ways to trigger a skill, and you can use both.

Way 1: Ask in plain English

Claude matches your request to the right skill automatically.

You saySkill used
Help me optimize this landing page for conversionscro
Write homepage copy for my SaaScopywriting
Set up GA4 tracking for signupsanalytics
Create a 5-email welcome sequenceemails

Way 2: Call a skill by name

Type a slash and the skill name: /cro, /emails or /seo-audit.

Tips for better results

  • Give context: paste the page URL, the file path or the draft you want improved.
  • Ask for one job per prompt, such as "audit" first, then "rewrite".
  • Chain skills: run customer-research, then feed the findings into copywriting, then test with ab-testing.
  • Ask a judgement question, like "is this A/B result real, can I stop the test?" Many skills are built to answer exactly that.
  • Skills reference each other, so Claude will often pull in a related skill on its own.

Ready-made workflows

Chain skills in order

Each workflow chains skills in order. Paste the prompts one at a time.

Fix a landing page that is not converting

  1. customer-research: "Pull the top objections and exact phrases from these reviews."
  2. cro: "Audit [URL] and tell me what to change first."
  3. copywriting: "Rewrite the hero and CTA using those customer phrases."
  4. ab-testing: "Plan a test for the new headline against the old one."

Launch a product or feature

  1. product-marketing: confirm your context file is current.
  2. launch: "Plan the launch of [feature] with a go-live checklist."
  3. emails: "Write the announcement and 3 follow-up emails."
  4. social: "Write launch week posts for LinkedIn and X."
  5. directory-submissions: "List the directories to submit to on launch day."

Get found in search and AI answers

  1. seo-audit: "Audit [URL] and rank the fixes."
  2. schema: "Add the right schema to my key pages."
  3. ai-seo: "Make my pages citable in ChatGPT and Perplexity."
  4. competitors: "Create comparison pages for my top 3 rivals."

Start B2B cold outbound

  1. prospecting: "Who should I target first and which signals matter?"
  2. cold-email: "Write a 3-step sequence for that audience."
  3. sales-enablement: "Write an objection-handling doc for replies."

Keep the customers you win

  1. onboarding: "Redesign the first session so users reach value faster."
  2. churn-prevention: "Design a cancel flow with a save offer."
  3. referrals: "Design a referral program with a reward."

Troubleshooting and extra resources

If something goes wrong

ProblemFix
Claude does not see the skillsCheck they sit in .claude/skills/, not only .agents/skills/, then restart the session. Or rerun npx skills add coreyhaines31/marketingskills -a claude-code.
/plugin is not availableYou are in a non-interactive or web environment. Use npx skills or the clone method.
Outputs feel genericRebuild your context file with the product-marketing skill and add more detail.
Old skill names like page-cro appearYou have v1 folders left over. See the upgrade note below.
Wrong skill gets usedCall the skill by name, such as /cro.

Upgrading from v1.x

Version 2.0 renamed 17 skills and merged page-cro and form-cro into cro. New skills install beside the old folders, so delete the stale ones from your install folder, then reinstall:

Terminal
rm -rf page-cro form-cro ab-test-setup analytics-tracking aso-audit competitor-alternatives email-sequence free-tool-strategy launch-strategy onboarding-cro paid-ads paywall-upgrade-cro popup-cro pricing-strategy product-marketing-context referral-program schema-markup signup-flow-cro social-content

Move your context file to the new location if you had one:

Terminal
mkdir -p .agents
mv .claude/product-marketing-context.md .agents/product-marketing.md
