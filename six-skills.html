Six free courses to take before the year ends

If you only learn six things about AI before 2027, make it these. All six courses are free to take. Work through them one at a time, starting with prompting.

The order matters. Prompting is the base everything else sits on, and you can get through a few chapters in one evening. After that, each course builds on what you already know.

01

Course 1 of 6

Write clear prompts

Anthropic's own prompting course on GitHub: 9 chapters with exercises. It is the base everything else sits on, and you can get through a few chapters in one evening.

What you will learn

  • How to structure a prompt clearly.
  • How to be clear and direct about what you want.
  • How to practise with the exercises in each chapter, instead of only reading.
At a glance
Length9 chapters with exercises
CostFree
WhereGitHub (Anthropic's interactive prompt tutorial)
PrerequisitesNone
Anthropic prompt engineering interactive tutorialgithub.com/anthropics/prompt-eng-interactive-tutorial
How to approach it

Do a few chapters in one evening, then use what you learned on a real task the next day.

The course is a set of notebooks on GitHub, so you work through it by running the exercises rather than watching videos. Check the repository's chapter list for the latest contents.

02

Course 2 of 6

Learn AI fluency

A free course on working well with AI, about 4 hours. It teaches a simple framework for deciding what to hand to AI, how to ask for it, how to judge the result and how to use it responsibly.

What you will learn

  • The "4 Ds" framework: Delegation, Description, Discernment and Diligence.
  • Two deep dives, on how generative AI works and on prompting techniques.
  • A certificate of completion at the end.
At a glance
LengthAbout 4 hours
CostFree
WhereAnthropic's course site (a free account on the course platform is needed)
PrerequisitesNone
AI Fluency: Framework & Foundationsanthropic.skilljar.com/ai-fluency-framework-foundations
How to approach it

Take it in two or three sittings. Apply one idea from each lesson to your own work as you go.

Anthropic also publishes versions for specific audiences, such as small businesses and builders, on the same course site.

03

Course 3 of 6

Build with Claude Code

Nine lessons on Claude Academy that show you how to build with Claude Code. You need a Claude plan to use it.

What you will learn

  • How to work with Claude Code on real tasks.
  • How to keep a long session on track and give Claude lasting instructions (such as a CLAUDE.md file).
  • How to check Claude's work before you trust it.
At a glance
Length9 lessons
CostFree course. You need a Claude plan to use Claude Code
WhereClaude Academy
PrerequisitesA Claude plan
Claude Code in Actionanthropic.skilljar.com/claude-code-in-action
How to approach it

Pair it with a small real project of your own so you build as you learn.

The course page describes Claude Code in more technical, developer-style terms than this list does. If you are new, start with our Claude Code starter guide first, then take this course.

04

Course 4 of 6

Connect AI with MCP

Build your own MCP server in about an hour. MCP is the standard way to connect Claude to other tools and data.

What you will learn

  • What MCP is and the three things a server can offer: tools, resources and prompts.
  • How to build a small MCP server and client.
  • How to test your server before you rely on it.
At a glance
LengthAbout an hour of building
CostFree
WhereAnthropic's course site
PrerequisitesSome Python helps. The course expects working knowledge of Python and a basic idea of JSON and HTTP
Introduction to Model Context Protocolanthropic.skilljar.com/introduction-to-model-context-protocol
How to approach it

Pick one tool you already use and decide what you would want Claude to do with it before you start.

This is the most technical course on the list. If Python is new to you, you can still follow along with Claude Code's help, or come back to it later.

05

Course 5 of 6

Turn your process into skills

Teach Claude how you work once and it reuses it every time. A skill is a saved set of instructions Claude follows automatically.

What you will learn

  • How to create your first skill.
  • How skills differ from other ways of customizing Claude Code.
  • How to share skills with others and fix them when they misbehave.
At a glance
LengthShort, self-paced
CostFree
WhereAnthropic's course site
PrerequisitesBasic familiarity with Claude Code and Markdown
Introduction to agent skillsanthropic.skilljar.com/introduction-to-agent-skills
How to approach it

Choose one task you repeat every week, write down how you do it, and turn that into your first skill.

Our business agents SOP shows ten skills built for real workflows, if you want examples to copy.

06

Course 6 of 6

Learn how agents work

Andrew Ng's agentic AI course on DeepLearning.AI. It is free to audit.

What you will learn

  • The core agentic design patterns: reflection, tool use, planning and multi-agent workflows.
  • How to evaluate whether an agent works.
  • How agents are put together, in five modules.
At a glance
LengthAbout 10 hours across 5 modules
CostFree to audit
WhereDeepLearning.AI
PrerequisitesIntermediate Python, and a basic idea of large language models and APIs
Agentic AI (DeepLearning.AI)deeplearning.ai/courses/agentic-ai
How to approach it

Take one module a week alongside your other projects. It is the longest course on the list.

Free to audit means you can watch the videos and join the community forum. Graded assignments, project tools and a certificate need a paid membership.
