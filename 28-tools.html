Part 1

Skills

Instruction files that teach Claude how to perform specialized tasks. Upload to a Project or install via the plugin marketplace.

01

Humanizer

Skill

Takes any AI-generated text and rewrites it to sound like a real person wrote it. It scans for 24+ common AI writing patterns (overuse of em dashes, perfectly balanced paragraphs, robotic transitions) and strips them out. You can feed it samples of your own writing so it matches your personal voice and sentence rhythm.

BEST FOR
  • Email drafts that sound like you
  • LinkedIn posts without AI tells
  • Sales copy that reads naturally
  • Client-facing documents
HOW TO INSTALL

In Claude.ai: Upload the SKILL.md file to your Project. In Claude Code: use the command below.

Terminalnpx skills add https://github.com/humanizer-ai/humanizer --skill humanizer
Source: GitHub
02

Caveman

Skill

Ultra-compressed communication mode that cuts Claude's token usage by roughly 75%. It drops filler words, articles, and pleasantries while keeping full technical accuracy. This saves you money on API usage and keeps responses fast and scannable. Over 438,000 installs and 98,000+ GitHub stars make it one of the most popular Claude skills in existence.

BEST FOR
  • Cutting API costs on long sessions
  • Getting straight-to-the-point answers
  • Coding sessions where you want code, not essays
HOW TO INSTALL

Install via the command below, then say "caveman mode" or type /caveman to activate.

Terminalnpx skills add https://github.com/juliusbrussee/caveman --skill caveman
Source: GitHub (Originally by Matt Pocock, MIT)
03

Skill Creator

Official Anthropic Skill

Anthropic's official skill for building your own custom skills. It walks you through an interactive Q&A process and generates a properly structured SKILL.md file. Instead of learning the format yourself, you describe what you want the skill to do and it produces the complete package. This is how you turn any repeatable workflow into a one-command operation.

BEST FOR
  • Building custom skills for your own workflows
  • Encoding your SOPs into reusable Claude instructions
  • Creating brand-voice or process skills for your team
HOW TO INSTALL

In Claude.ai: already available as a built-in skill when Code Execution is enabled. In Claude Code: install from the official marketplace.

Terminal/plugin install skill-creator@claude-plugins-official
Source: Anthropic Official Skills Repository
04

Find Skills

Built-in Feature

The built-in skill discovery system inside Claude Code and Claude Desktop. Use the /plugin command to browse the Discover tab, search by keyword, and install any skill from the official or community marketplaces. In Claude.ai, you can type /anthropic-skills: followed by a skill name to invoke built-in Anthropic skills directly. Think of it as the app store for Claude capabilities.

HOW TO USE

In Claude Code, type /plugin and navigate to the Discover tab. Search for any skill or plugin by name. In Claude.ai, type /anthropic-skills: in the message box to see available built-in skills. No separate installation needed.

Claude SEO

Community Skill

Open-source skill pack created by Y Combinator CEO Garry Tan. Turns a single Claude Code instance into a virtual engineering team with 9+ specialist roles: a CEO who reviews product decisions, an engineering manager for architecture, a designer who catches AI slop in UIs, a security reviewer, a QA lead that opens a real browser and tests your app, and a release manager for git workflows. Source: GitHub (85K+ stars, by Garry Tan)

Codex

Community Skill

Delegates coding tasks to OpenAI's Codex CLI, running in a completely separate process from Claude. This gives you a second AI model reviewing your code from a different perspective. Adds /codex:review, /codex:adversarial-review, and /codex:rescue commands. Fire off a code review to Codex, keep working with Claude in the foreground, and check results when done. Every AI model has blind spots; running two eliminates more of them.

HOW TO INSTALL

Requires OpenAI Codex CLI (npm install -g @openai/codex) and an OpenAI API key. Then install the plugin.

Terminal/plugin marketplace add veithly/codex-skill /plugin install rick@codex-skill
Source: GitHub (MIT License)

MCP Builder

Official Anthropic Skill

Guides Claude through building high-quality MCP (Model Context Protocol) servers in Python or TypeScript. MCP is the open standard that powers how Claude connects to external services. This skill handles tool definitions, schemas, and transport wiring so you can hook Claude up to any API or database. If the connector you need does not exist yet, this is how you build it yourself.

HOW TO INSTALL

Already built into Claude.ai when Code Execution is enabled. For Claude Code, it is part of the official skills set.

Source: Anthropic Official Skills Repository

Part 3

Connectors

Permission-controlled bridges between Claude and your external tools. Connect once and Claude can read, draft, and act across your entire stack.

HOW TO CONNECT ANY CONNECTOR

In Claude.ai or the Claude app, go to Settings, then Connectors. Search for the service you want. Click Connect. Sign in to your account and authorize access. Done. No API keys, no code. The same sign-in flow you use everywhere else.

Frequently Asked Questions

What is the difference between Skills, Plugins, and Connectors?

Skills are instruction files (SKILL.md) that teach Claude how to do a specific task. They load on demand and use very few tokens until activated. Plugins are bundles of skills, agents, hooks, and MCP servers that install as a single unit in Claude Desktop. Connectors are permission-controlled bridges that let Claude read from and write to external apps like Gmail, Slack, and Google Drive using the MCP (Model Context Protocol) standard.

Do I need Claude Code to use these?

Not for everything. Skills work in Claude.ai (with Code Execution enabled) and in Claude Code. Plugins require Claude Desktop with Cowork. Connectors work in Claude.ai, the Claude mobile app, and Claude Desktop. The majority of these tools are accessible to non-developers.

Are these tools free?

All Anthropic-published skills and plugins are free. Most community skills are open source and free. Connectors are free to connect but require a Claude Pro, Team, or Enterprise plan. Some connectors link to paid third-party services (like GoHighLevel or Apify), but the connector itself costs nothing.

Can I install all 28 at once?

You can, but do not overwhelm yourself. Start with the tools most relevant to your work today. Skills and plugins add minimal token overhead (tens of tokens per skill until triggered), so having many installed does not slow Claude down. Add connectors as you need them.

How do I install a skill in Claude.ai (no terminal)?

Go to a Claude Project, open Project Settings, and upload the SKILL.md file. Alternatively, paste the skill instructions into the Project's custom instructions field. Claude will load the skill automatically when it detects a relevant task. You can also use the /anthropic-skills: prefix in the message box to invoke any built-in Anthropic skill.
