Build a Morning Brief agent that watches everything for you.

What you are building

A single Claude agent that runs on a schedule, checks four tools on your behalf, and sends you one briefing instead of four. No opening Calendar, then Asana, then Gmail, then Slack. It runs in the cloud, so it can finish before you sit down.

Who this is for: founders and operators who start every day piecing together the same four apps to work out what needs attention.

Tools needed:

  • A Claude account with scheduled tasks available
  • Google Calendar connector
  • Asana connector
  • Gmail connector
  • Slack connector
01

Connect your tools

Claude needs read access to each tool before it can check anything. Connect all four before writing a single instruction.

  1. Open your Claude connector settings and connect Google Calendar.
  2. Connect Asana with access to your assigned tasks.
  3. Connect Gmail with read access to your inbox.
  4. Connect Slack with access to your DMs and mentions.
Note

Cloud connectors are what let this task run while your laptop is asleep. If a future version needs a local folder or a desktop-only app, that step will need the desktop app open on a running computer.

02

Set your priorities before you build anything

The agent cannot guess what counts as urgent. Write down your rules first, in plain language, and save them as instructions the agent reads every run.

  1. List what counts as noise in your inbox: newsletters, automated notifications, receipts.
  2. Define what makes something urgent enough for an extra alert outside the daily brief.
  3. Decide the order you want information in: oldest overdue first, most recent first, or by tool.
Important

These rules will not be right on the first attempt. That is expected. Step 10 covers how corrections become permanent instructions instead of one-off fixes.

03

Build the Calendar check

Give the agent a clear window and a clear job: look ahead, not just at today.

Instruction Check Google Calendar for today and the next three days. Record the time and title of every event. Flag any two events that overlap or sit less than 15 minutes apart.
04

Build the Asana check

Surface what is actually due, not the entire backlog.

Instruction Check Asana for incomplete tasks assigned to me. Sort overdue tasks and tasks due today to the top. Within that group, order by oldest due date first.
05

Build the Gmail check

This is the step where your noise list from Step 2 does the most work.

Instruction Search Gmail for unread messages from the last 24 hours. Remove newsletters, automated notifications, receipts, and other low-signal mail. Surface only messages that need my attention or a decision, with sender and a one-line summary.
06

Build the Slack check

Slack threads get long. Ask for the summary, not the transcript.

Instruction Check Slack for direct messages and mentions from the last 24 hours. Summarise each relevant conversation in one to two lines. Pull out any unanswered questions or open action items directed at me.
07

Combine into one briefing

Four checks, four sections, then one summary that pulls the most time-sensitive item from each.

SourceWhat it contributesPlaced in section
CalendarTimes, titles, conflictsCalendar
AsanaOverdue and due-today tasksAsana
GmailEmails needing a decisionGmail
SlackOpen questions, action itemsSlack
All fourMost time-sensitive items across sourcesAction Items
Instruction Combine the four checks into one briefing with separate sections: Calendar, Asana, Gmail, Slack. Build one Action Items section at the end using the most time-sensitive information pulled from all four sections.
08

Set the delivery format

Format for a phone screen. A wall of text at 7am does not get read.

  1. Send the briefing as a private Slack message to yourself.
  2. Use short section headers and short lines, not dense paragraphs.
  3. Only send a separate alert when something is genuinely urgent or blocking. A normal day should arrive quietly.
09

Create the scheduled task

This is the piece that puts the agent on shift without you starting it manually.

  1. Open Claude's scheduled tasks and create a new recurring task.
  2. Set the run time to before your usual start of day.
  3. Paste in the combined instruction set from Steps 3 through 8.
  4. Confirm the task only uses cloud connectors so it can run before you open your laptop.
Tip

Each morning the scheduled task starts a fresh session and follows the saved instructions from scratch. It does not carry over yesterday's conversation, only the instructions you have saved.

10

Test, correct, and save the learning

This system does not arrive finished. It gets useful through review.

  1. Read the first few briefings closely and note anything wrongly filtered as noise or urgent.
  2. Correct the instruction, not just that day's output.
  3. Save the correction into the standing instructions so it applies to every future run.

FAQs

Can this run while my laptop is asleep?

Yes, as long as the task only uses cloud-based connectors and files saved to your Claude account. Anything needing a local folder, browser, or app on your machine needs the desktop app and a running computer.

Do I need to build this before finishing my Business Brain?

No. The context and connections set up in that earlier work are what make this brief useful. Build this after, not before.

What if the briefing feels too long?

Tighten the instructions in Step 2. A briefing that is too long usually means the noise filter needs another pass, not that the format is wrong.
