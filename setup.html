Setup Guide

Set up Claude like a pro

Four steps to get Claude working properly on day one, even if you opened it for the first time this morning.

10 min setup 4 steps Updated August 2026
What you need
  • A Claude account, free or paid
  • A computer to install the desktop app on
  • Login access to the daily tools you want connected, such as Gmail, Calendar, or Slack
01

Download the desktop app

Work in the app instead of a browser tab. The desktop app can reach files already sitting on your computer, so you stop uploading things one at a time like it is 2019.

Note

If you already work entirely in the browser, this step is optional. Everything after it still applies.

02

Turn on the memory settings

Go to Settings then Memory and turn on both toggles.

  • a.Turn on the toggle that lets Claude search back through chats you have already had.
  • b.Turn on the toggle that lets Claude generate and hold on to context from those chats going forward.
03

Connect your tools

Connect the tools you use daily, such as Gmail, Calendar, and Slack, so Claude can work with them directly instead of waiting on you to copy something out and paste it back in.

04

Create one project

Create a project and use it as the single place for everything about your business. Everything you drop in there stays in there, and Claude remembers all of it going forward.

Check your setup

Desktop app installed and signed in
Both memory toggles turned on in Settings
At least one daily tool connected
One project created for your business

What to do next

  • Drop your core business documents into the project so Claude has context before you ask it anything.
  • Send one real task through a connected tool to confirm the connection actually works.
  • Start a chat inside the project instead of a blank chat, so memory has something to build on.
