Sort your camera roll with Claude.

Purpose

What this does

You paste one prompt into Claude Code and it builds a single index.html that sorts a folder of photos and videos into subfolders on your computer. It needs no server, no build step and no paid APIs.

While it works, the page plays a satisfying animation of thumbnails flying from a pile into category cards, which makes a ready-made screen recording for social media. When you confirm, it actually moves or copies the files, and Undo puts everything back.

Who this is for

  • Founders and creators with a messy camera roll
  • Anyone filming a sort-my-photos reel
  • Beginners who want to build a tool from one prompt

Tools needed

  • Claude Code (desktop Code tab or terminal)
  • Google Chrome or Microsoft Edge
  • A folder of photos and videos
  • A screen recorder (optional)
Build it or download it
This SOP has you build the sorter yourself from a prompt. Categories come from colour, brightness, shape and video length, with no AI model involved. For a ready-made file that uses a local AI model, see the AI File Sorter SOP.
01

Part 1 · Build it

Open Claude Code in an empty folder

  1. Open Claude Code: the Code tab in the Claude desktop app, or the terminal.
  2. Create a new empty folder, for example photo-sorter, and open it as your project.
  3. Start a new session.
Tip
An empty folder keeps Claude's output to a single index.html, so there is nothing to mix up later.
02

Part 1 · Build it

Paste the build prompt

Copy the whole prompt below and paste it into Claude Code in one go. It describes the look, the animation, how files are categorised, and the safety rules for moving files.

Build prompt: Photo Sorter

Prompt
Build me a "Photo Sorter": one self-contained index.html file (no build step, no server, no paid APIs) that I open in Google Chrome. It sorts a folder of photos and videos into subfolders on my computer, with a satisfying animation I can screen-record for social media.

## Look and feel
- Calm, minimal "app window": light warm-grey background, one big rounded off-white card filling the screen, thin borders, soft shadow.
- Fonts from Google Fonts: Inter for UI, Instrument Serif italic for one highlighted word.
- Header: small breadcrumb "Personal / Sorter", then a big title "Sorting my [folder name] folder". The folder name is in italic serif and filled in automatically from the folder I pick. Clicking the title lets me edit it.
- Stats row under the title: Total files · Photos · Videos · Duplicates · Space to free. Big bold numbers with tiny uppercase grey labels.
- Three columns below:
  - Left: "Photos" with 6 category cards in a 2×3 grid.
  - Middle: the "pile" area, with a small status line underneath ("Scanning… 312 / 1,065", "Press Sort", "All sorted ✓ in 6.4s").
  - Right: "Videos" with 3 cards, then "Cleanup" with 2 cards.
- Each category card: coloured dot, name, a count pill on the right, and an empty area where thumbnails land in a neat grid.
- A small dark floating toolbar in the bottom-right: Choose folder, Demo, Replay, Sort, Organise.

## The animation (this is the money shot)
1. Scanning: each file gets a square thumbnail that pops into the middle with a little bounce. Together they form a big circular pile, laid out in a sunflower spiral (phyllotaxis) from the centre outward. Tiles overlap slightly, are randomly tilted, and have a white border and soft shadow like tiny polaroids. The whole pile rotates very slowly. "Total files" counts up as tiles appear.
2. Sorting (Space key or the Sort button): tiles leave the pile in random order, slowly at first and then faster and faster. Each one flies along a curved arc into its category card, straightens out and shrinks to fit that card's grid. Each card's count pill bumps as a tile lands, and the stats count up live. The whole sort takes 5–8 seconds no matter how many files there are.
3. Done: the status says "All sorted ✓ in X.Xs" and the Organise panel appears.
- Performance: one requestAnimationFrame loop and only CSS transforms (translate, rotate, scale). Never animate width, height, top or left. Animate at most 1,500 tiles, but still sort and organise every file.
- Each card works out its own tile size so all its files fit inside it.

## How files are categorised (all in the browser, no AI API)
For each image, draw a 96px centre-cropped thumbnail on a canvas and read its average colour, its brightness and whether it's taller or wider. For videos, read the duration from the metadata and grab a frame at 1 second for the thumbnail. Run 6 files at a time.
- Photos/Screenshots: the filename contains "screenshot", or it's a PNG with a phone-screen shape.
- Photos/Night & moody: brightness below 0.3.
- Photos/Golden hour: clearly more red than blue, and not dark.
- Photos/Sky & sea: more blue than red.
- Photos/Portrait shots: taller than wide.
- Photos/Everyday shots: everything else, including images the browser can't decode (like HEIC in Chrome).
- Videos/Quick clips (under 10s), Videos/B-roll (10–60s), Videos/Long takes (over 60s).
- Duplicates: files with exactly the same content. Only hash files that share the same byte size (SHA-256 with crypto.subtle; for files over 8 MB, hash the first and last 4 MB). Keep the copy with the shortest name as the original.
- Docs & other: everything else, shown as a pale tile with the file extension (PDF, ZIP…).

## Actually organising the files (safety first)
- Use the File System Access API: showDirectoryPicker({ mode: "readwrite" }). Also let me drag a folder onto the page.
- Only touch files directly inside the chosen folder. Never go into its subfolders.
- After the animation, show a panel in the middle: "Organise N files? They'll go into X folders inside [folder]. Nothing gets deleted: duplicates go into their own folder so you can check them first." Give me a toggle between "Move files" and "Copy, keep originals", plus the buttons "Organise my files" and "Not now".
- Show a progress bar while it works, handling 4 files at a time.
- Moving: use FileSystemHandle.move() when the browser supports it. Otherwise copy the file, check the copy is the same size, and only then remove the original.
- Never overwrite: if a name already exists in a folder, save it as "name (1).jpg".
- NEVER delete my files. Duplicates are moved into a Duplicates folder, not deleted.
- Keep an undo log. When it's done, show "✓ N files organised", plus an Undo button that puts every file back where it was and removes any empty folders the tool created.
- If some files fail, keep going and list those files at the end.
- In Safari or Firefox, still show the animation, but explain that organising for real needs Chrome or Edge.

## Extras
- A Demo button that makes about 600 fake colourful "photos" (sunsets, night skies, ocean, screenshots, a few videos, docs and duplicates), so I can try the animation without choosing a folder. In demo mode, Organise only explains that it's a demo.
- Keyboard: Space = sort, R = replay the animation for another take (without scanning again), H = hide or show the toolbar, F = fullscreen.
- The toolbar fades out while sorting, so recordings look clean.

## Before you give it to me
- Run the Demo in a browser and check the animation works with no console errors.
- Test move, copy and undo on a throwaway test folder (for example, the browser's Origin Private File System filled with a few generated images, a duplicate, a PDF and a video). Never test on my real files.
- Then tell me in plain steps how to open it in Chrome, and what to do if Chrome won't let it edit a folder opened straight from a file (offer a one-line local server command as a backup).
Important
Do not trim the safety section. It is what stops the tool overwriting or deleting files, and it tells Claude to test on a throwaway folder, never your real photos.

Part 1 · Build it

Let Claude build and test it

Claude writes the file, runs the Demo, and tests move, copy and undo on a generated test folder. Wait until it reports the results.

  1. Answer any question Claude asks about your setup.
  2. Check that Claude says the Demo ran with no console errors.
  3. Check that Claude reports move, copy and undo working on a test folder.
  4. Confirm the folder now contains index.html.
  5. Ask Claude to fix anything it flagged before you continue.
04

Part 2 · Before you sort

Prepare your photos

Do these three things before you point the sorter at real files.

Never pick your Photos Library

On a Mac, iPhone photos live inside Photos Library.photoslibrary. Moving files in there can break the Photos app. Export copies first.

Export as JPEG

  1. In the Photos app, select your photos.
  2. Choose File > Export > Export Photos…
  3. Set Photo Kind to JPEG.

Chrome cannot read iPhone HEIC files, so they would all land in Everyday shots instead of being sorted by colour.

Try a small folder first

Copy around 20 photos into a new folder and run it there. Once you have seen Move and Undo work, use it on the big one.

Warning
Only files directly inside the folder you choose are touched. Subfolders are ignored, so put everything to sort at the top level.
05

Part 3 · Run it

Open it in Chrome

  1. Open index.html in Google Chrome. Chrome or Edge is needed to organise files for real.
  2. Safari and Firefox still show the animation, but cannot write to folders.
If Chrome won't let it edit a folder
Some setups block folder access for pages opened straight from a file. Ask Claude for the one-line local server command, run it, and open the address it gives you instead.
06

Part 3 · Run it

Choose your folder

  1. Click Choose folder in the toolbar at the bottom right, or drag a folder onto the page.
  2. Pick your small test folder.
  3. When Chrome asks, choose Edit files to allow editing.
  4. Watch the scan: a pile of thumbnails builds in the middle and Total files counts up.

The title fills in automatically, for example "Sorting my Test folder". Click it to edit the name for your video.

07

Part 3 · Run it

Sort with the animation

  1. Wait for the status to read Press Sort.
  2. Press Space or click Sort.
  3. Tiles fly into their category cards over 5 to 8 seconds, however many files there are.
  4. When the status reads All sorted ✓, the Organise panel appears.
Filming tip
Press H to hide the toolbar and F for fullscreen, then start your screen recorder before pressing Space. Press R to replay the animation for another take without scanning again.
08

Part 4 · Move the files

Organise the files

The animation is only a preview. Nothing moves on your computer until you confirm in the Organise panel.

  1. Read the panel: how many files, how many folders, and where they will go.
  2. Choose Move files, or Copy, keep originals to leave the originals where they are.
  3. Click Organise my files, or Not now to stop.
  4. Watch the progress bar. Files are handled four at a time.
  5. Wait for ✓ N files organised.
Safety built in
Existing names are never overwritten: a clash is saved as name (1).jpg. If some files fail, the tool keeps going and lists them at the end.
09

Part 4 · Move the files

Undo if needed

  1. Click Undo on the finished screen.
  2. Every file goes back to where it was.
  3. Any empty folders the tool created are removed.
Warning
Undo is available right after organising. Do not close the tab until you are happy with the result.
10

Part 4 · Move the files

Review the Duplicates folder

  1. Open the folder you sorted in Finder or File Explorer.
  2. Open the Duplicates folder and look through it.
  3. Delete it yourself when you are happy. The tool never deletes anything.

Duplicates are files with exactly the same content. The copy with the shortest name is kept as the original.

FAQs

Questions answered

Does it upload my photos anywhere?

No. Everything runs in your browser with no server and no paid AI API. Files are categorised from their colour, brightness, shape and video length.

Will it delete my files?

No. Duplicates are moved into a Duplicates folder for you to review, and Undo puts every file back where it was.

Why do my iPhone photos all land in Everyday shots?

Chrome cannot read HEIC files. Export the photos as JPEG from the Photos app first, then sort the exported folder.

Does it sort files inside subfolders?

No. It only touches files directly inside the folder you choose.

Which browsers work?

Chrome or Edge to organise files for real. Safari and Firefox show the animation but cannot write to folders.
