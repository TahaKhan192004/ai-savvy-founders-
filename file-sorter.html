Purpose

What this does

The AI Savvy Sorter is one HTML file. You open it in your browser, point it at a folder, and an AI model running on your laptop looks at every photo and video, then copies or moves each one into a category folder.

Your files never leave your computer. The only thing downloaded from the internet is the AI model itself (CLIP), and that happens once. While it works, the page plays a full-screen animation of the files being sorted, so the run doubles as a ready-to-record clip.

Who this is for

  • Founders and creators with a messy Downloads or camera folder
  • Anyone filming an "AI agent sorts my files" reel
  • Team members running the tool for the first time

Tools needed

  • Desktop Chrome or Edge
  • The file AI-Savvy-Sorter.html
  • An internet connection for the first model load
  • A folder of photos and videos
  • A screen recorder (optional)

01

Save the sorter file

AI-Savvy-Sorter.html

Single HTML file · ~167 KB · Opens in Chrome, nothing to install

Download Sorter ↓
  1. Download AI-Savvy-Sorter.html and save it somewhere easy to find, such as your Desktop.
  2. Keep it as a single file. There is nothing to install and no other files to keep next to it.
Note
The page loads the AI library from cdn.jsdelivr.net and the model from huggingface.co. If your office network or VPN blocks either one, the model will not load.
02

Open it in Chrome or Edge

  1. Right-click the file and choose Open with then Google Chrome (or Microsoft Edge).
  2. Confirm you see a cream panel titled The sorter on top of a dark screen.
Warning
Safari and Firefox can show the preview, but they cannot create folders or write files. If you see "This browser can't write folders" in the panel, switch to Chrome or Edge.
03

Wait for the AI model to load

  1. Look at the status bar with the small dot inside the panel. On first use it reads AI model: downloading X / Y MB (first time only).
  2. Wait until the dot turns green and the text reads AI model: ready, running on this laptop.
Tip
The browser keeps the model after the first download, so later runs get to "ready" in seconds. Do the first load before you sit down to film.
04

Prepare the folder to sort

  1. Create a new folder inside the one you want to clean, for example Downloads/To sort.
  2. Move the photos and videos directly into it. Files inside subfolders are ignored.
  3. Keep each run at 1,500 files or fewer. Anything beyond that is skipped.
Important
Chrome does not let web pages open system folders like Downloads, Desktop or Documents directly. That is why you sort a folder inside them instead.
TypeFormats picked up
Photosjpg, jpeg, png, webp, gif, bmp, avif, heic, heif
Videosmp4, mov, m4v, webm, mkv, avi
05

Set the headline folder name

  1. Find the field Folder name in the headline.
  2. Type the name you want on screen, for example Downloads. The headline "Sorting my ___ folder" updates as you type.
Note
Choosing a folder in the next step replaces this field with the real folder name. If you want the headline to say "Downloads" while sorting "To sort", retype it after Step 6.
06

Choose the folder

  1. Click Choose folder, or drag the folder onto the dashed box in the panel.
  2. Select your To sort folder and confirm.
  3. Approve Chrome's permission prompts so the page can view and edit files in that folder.
  4. Watch the status line move from Reading files… n/N to N files loaded. Analysing…
Warning
If the status says "preview only, nothing will be written", the edit permission was declined. Click Choose folder again and allow editing.
07

Choose copy or move

  1. Leave Create the folders on disk and put files in them ticked to actually sort files.
  2. Tick Move files instead of copying (originals are removed) only if you want the loose files gone afterwards.
SettingWhat happens
Create folders ticked, Move untickedCopies each file into its category folder. Originals stay where they were. Safest choice.
Create folders ticked, Move tickedPuts each file into its category folder and deletes the loose original.
Create folders untickedAnimation and sorting only. Nothing is written to disk.
Important
Moving cannot be undone from the page. Run a copy first if this is your first time with a folder that matters.
08

Let it analyse

  1. Wait while the status counts up: Analysed n / N files.
  2. Continue when it reads All N files analysed. Press Space.

Each file goes through these checks in order:

CheckResult
Photo filename contains "screenshot"Screenshots
Video filename contains "screen recording" or "RPReplay"Screen recs
Video longer than 90 secondsLong takes
File the browser cannot read (for example HEIC)Other
Everything elseThe AI compares the image to each folder's descriptions and picks the closest match
Tip
You can press Space before analysis finishes. The scan animation simply keeps running until every file has a folder, then sorting starts.
09

Set up your recording

  1. Click an empty part of the page so no text field is focused.
  2. Press F to go fullscreen.
  3. Start your screen recorder (QuickTime, OBS, or the built-in recorder on your computer).
KeyAction
SpaceStart sorting. The panel hides automatically.
RReplay the animation after a finished run
HShow or hide the control panel
FToggle fullscreen
10

Press Space to sort

  1. Press Space.
  2. Watch the pill above the sphere move through each phase:
Analysing Sorting Copying files / Moving files Complete
  1. Stop recording once the "All sorted" screen appears.
Note
Keep the tab open and in front until "Complete" shows. Files are still being written during the "Copying files" phase, even after the animation ends.
11

Check the results

  1. Open the sorted folder in Finder or File Explorer.
  2. Confirm there is one subfolder per category that received files.
  3. Spot check a few folders. Files with the same name are saved as name (1).jpg instead of overwriting.
  4. If the pill reads N could not be written, move those leftover files into a fresh folder and run again.
12

Replay or run the demo

  1. Press R to replay the full animation for a second take. Writing is switched off automatically, so files are not copied twice.
  2. Press H and click Demo (no AI, no files) to run 900 random tiles with no model and no disk access. Useful for rehearsing the recording.
13

Customize the folders (optional)

  1. Open AI-Savvy-Sorter.html in a text editor such as VS Code or Notepad.
  2. Search for PHOTO_FOLDERS near the top of the script.
  3. Rename a folder, or edit its descriptions. Keep descriptions short and visual, the way you would describe the photo to a friend.
  4. Save the file and reload the page. The model rebuilds its folder list on load.
JavaScript
// Example: add a "Client work" folder for photos
{name:"Client work", prompts:[
  "a photo of a laptop screen with a website design",
  "a printed brand style guide on a desk",
  "a product mockup photo"
]},

You can also adjust the timing at the top of the script:

SettingDefaultControls
LONG_TAKE_SECONDS90Videos longer than this go to Long takes
SCAN_SECONDS1.8Minimum length of the scan sweep
SORT_SECONDS10Length of the sorting animation
FLIGHT_MS1000Flight time of each thumbnail, in milliseconds
Tip
For a 15 second reel, set SORT_SECONDS to 8 so the whole sort fits in one shot with room for the "All sorted" screen.

Troubleshooting

When something stalls

What you seeWhyFix
"Chrome won't open that folder directly"You picked a system folder such as DownloadsCreate a subfolder inside it, move the files there, and pick that subfolder
"No photos or videos found in that folder"Files are inside subfolders, or the formats are not supportedMove the files to the top level of the chosen folder
"AI model failed to load"A firewall or VPN blocks cdn.jsdelivr.net or huggingface.coTurn off the VPN or switch networks, then reload the page
Pill stuck on "Loading AI"The model is still downloadingWait. Check the green dot status with H
"preview only, nothing will be written"Edit permission was declined, or the write box is untickedTick the write box, click Choose folder again and allow editing
Lots of photos in OtherThey are HEIC files Chrome cannot readExport them as JPG first, or sort them by hand
"N could not be written"Disk is full or a file is locked by another appFree up space, close other apps, rerun with the leftover files

FAQs

Questions answered

Does the AI Savvy Sorter upload my photos?

No. The AI model downloads once and then runs inside your browser on your laptop. Your photos and videos are never sent anywhere.

Does it sort files inside subfolders?

No. It only reads photos and videos sitting directly inside the folder you choose, up to 1,500 files per run.

Why do my HEIC photos land in Other?

Chrome cannot decode HEIC images, so the model cannot look at them. They are still copied or moved into a folder called Other.

Can I change the folder categories?

Yes. Open the HTML file in a text editor and edit the PHOTO_FOLDERS and VIDEO_FOLDERS lists near the top of the script. See Step 13.

Which browsers does it work in?

Desktop Chrome or Edge for full sorting. Other browsers can run the preview but cannot create folders or write files.
