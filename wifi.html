Speed up your Wi-Fi with Claude

Use Claude Code to find what is slowing your router down, then remove devices you do not recognise.

  • About 10 minutes
  • Beginner
  • Updated 24 Nov 2026
Purpose
Scan your router with Claude, apply the fixes you approve, and compare your speed before and after.
Who it is for
Anyone who can log in to their own router.
You need
The Claude desktop app with the Code tab, a computer on the Wi-Fi you want to fix, and your router admin login.
01

Open Claude Code and paste the prompt

  1. Open the Claude desktop app on a computer connected to the Wi-Fi you want to fix.
  2. Click the Code tab.
  3. Paste this prompt and press Enter:
    Prompt 
    Connect to my router and find everything that's slowing my Wi-Fi down.

Note

Use the desktop app, not Claude Code on the web. The web version runs in the cloud and cannot reach your home router.

02

Sign in to your router

  1. Let Claude find your router on your network.
  2. When it asks for the login, type in the router admin password. It is usually printed on the sticker on the back of the router.
03

Review the scan and approve the fixes

  1. Note the speed test result Claude reports first. This is your before number.
  2. Read the list. Claude checks which background apps are using your internet and whether nearby Wi-Fi networks clash with yours.
  3. Ask Claude to explain each change and how to undo it.
  4. Reply yes to apply the fixes.
  5. Let Claude run the speed test again and compare it with your before number.

Important

Claude changes real router settings, so approve only what you understand. Results depend on your router, your plan, and what was slowing it down.

04

Remove devices you do not recognise

  1. Paste this prompt:
    Prompt 
    Show me every device connected to my Wi-Fi and flag anything you don't recognise.
  2. Check the list against the devices you own.
  3. Tell Claude which ones are yours.
  4. Ask Claude to block the rest.

Tip

If one of your own devices loses connection, ask Claude to unblock it.

FAQ

Quick answers

Why use the desktop app instead of Claude Code on the web?

The desktop app runs on your computer, so it can reach the router on your home network. Claude Code on the web runs in the cloud and cannot see your router.

What if the password on the router sticker does not work?

Some stickers list only the Wi-Fi password. Look for a line labelled admin or login, or ask your internet provider for the router admin login.

Can I undo the changes Claude makes?

Yes, if you ask first. Before you approve the fixes, ask Claude to list each change and how to reverse it, then keep that list.
