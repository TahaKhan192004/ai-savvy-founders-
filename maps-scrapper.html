How this works

The Google Maps Scraper Kit pulls clean lead lists from Google Maps: business name, phone, website, rating, and address. Normally, setting this up would mean typing technical commands into a terminal. In this guide, you do not do that. You use Claude Code inside the Claude Desktop app, and you just tell it what you want in plain English. Claude runs every technical step behind the scenes.

Important

This tool pulls data directly from Google Maps, which is against Google's Terms of Service. Use it responsibly, one job at a time, and follow data protection rules such as GDPR or CCPA for any phone numbers or emails you collect.

What you need

A Mac, Windows, or Linux computer
Docker Desktop, a free app that runs the scraper quietly in the background
Claude Desktop, with the built-in Code tab you'll use for every step
The GitHub link for the Google Maps Scraper Kit, or the kit folder if someone shared it with you directly
01

Install Docker Desktop

Docker Desktop is the app that quietly runs the scraper on your computer. You will not need to open it or click anything inside it once it is installed.

  1. a.Go to docker.com/products/docker-desktop and download the version for your computer
  2. b.Open the installer and follow the on-screen steps, using all the default options
  3. c.Open Docker Desktop once so it finishes starting up, then leave it running in the background
Note

You do not need to understand Docker to use it. Think of it as the engine under the hood. Claude Code will check that it is running for you later, so nothing more to do here.

02

Install Claude Desktop

Claude Desktop is the app that does the technical work in every step from here on, through its built-in Code tab.

  1. a.Go to claude.com/download and install the app for your computer
  2. b.Open the app and sign in with your Claude account
03

Open a folder in Claude Code

No terminal needed. You just need an empty folder ready for Claude to work in, then point Claude Desktop at it with a couple of clicks.

  1. a.Create a new, empty folder on your computer and name it something like "Google Maps Scraper"
  2. b.In Claude Desktop, click the Code tab at the top, next to Chat and Cowork
  3. c.Choose Local to work with files on your own computer
  4. d.Click Select folder and choose the empty folder you just created

A chat box opens for this project. Everything from here is just typing sentences into that box, starting with getting the actual kit files into this folder.

04

Get the kit files from GitHub

The folder you selected is empty. Ask Claude to pull the actual kit files into it from GitHub.

Say this to Claude Code
"Please clone the Google Maps Scraper Kit repo into this folder: [paste the repo link here]"

Replace the bracketed part with the actual GitHub link before you send it. Claude checks whether git is installed, installs it if needed, clones the repository into the folder, and confirms once the files are there.

Note

If someone already shared the kit folder with you directly instead of a GitHub link, skip this step. Just select that shared folder in step 3 and move on to step 5.

05

Ask Claude Code to set everything up

Type the request below into the Claude Code chat box. It starts the scraper in the background and checks that it is ready.

Say this to Claude Code
"Please set up the Google Maps Scraper Kit for me. Start the scraper, confirm it's running, and let me know when it's ready to use."

Claude Code will start Docker running the scraper, check the connection, and tell you in plain English once everything is ready. If Docker is not open yet, ask Claude Code to check, and it will tell you what to do.

06

Run your first scrape

Tell Claude Code the type of business and the city you want. It handles everything: starting the search, waiting for it to finish, and turning the results into a table for you.

Say this to Claude Code
"Scrape coffee shops in Austin, Texas and give me a table with the name, phone number, and website for each one."

Swap in whatever business type and city you actually need. A first search usually takes one to two minutes to come back.

07

Understand what you get back

By default, Claude Code hands you a clean table with only the useful fields for outreach: name, phone, email, website, category, address, rating, and review count. Anything technical, like map coordinates or internal IDs, is left out so the list is easy to actually use.

Tip

Treat the list as leads to verify and reach out to, not as data to resell. Phone numbers and emails count as personal data, so follow the usual outreach and privacy rules where your business operates.

08

Ask for more detail if you need it

You can ask for extra information without changing anything on your end. Just say what you want.

Say this to Claude Code
"Can you also find their Instagram and LinkedIn pages if they have one?"

This scans each business's own website for links to their social pages, so it does not add any extra effort on your side. It is a bit slower, and coverage depends on whether a business actually links its socials.

09

Scale up without getting blocked

Google can temporarily block scraping from your internet connection if you run very large searches back to back. This clears itself after a while and never affects your Google account, but it does mean a search might come back empty or fail while it is happening.

Warning

If a search comes back empty, fails, or has far fewer results than usual, wait a while before trying again rather than running it right back.

For a big or repeated job, just ask.

Say this to Claude Code
"This is a bigger scrape, around 500 businesses across five cities. Can you set it up so we don't get rate limited?"

Claude Code will slow the pace down and add proxies if you have them, or tell you plainly if the job is risky as described.

10

Manage and stop jobs

You never need to touch a terminal command directly. Ask for what you want instead.

Say this to Claude Code
"Show me all the scrapes I've run so far." or "Delete that last job, I don't need it." or "I'm done for today, please stop the scraper."

Stopping the scraper when you are done frees up your computer's resources. Starting it again next time is just step 5, asking Claude Code to set everything up.

Good habits, at a glance

Start with small searches, then go bigger once you see clean results
Run one search at a time rather than several at once
Only ask for emails when you actually need them, since it slows the search down
Treat every list as leads to verify and contact respectfully, not data to resell
Ask Claude Code to stop the scraper when you are finished for the day

FAQs

Do I ever need to type a technical command myself?

No. Opening the Code tab and selecting the folder is done entirely with clicks. Everything after that is a plain English sentence in the chat box.

Can this find leads from Instagram or TikTok instead?

No. It only works with Google Maps listings. Ask Claude and it will tell you plainly if a request is outside what this tool does.

Will a block affect my Google account?

No. Only the internet connection making the requests is affected, and only temporarily. Your Google account is never banned.

What if I close the app and come back later?

Open Claude Desktop, click the Code tab, and open the same session or select the kit folder again. Your past results are still saved.

If something goes wrong

You do not need to diagnose anything yourself. Just describe what you are seeing to Claude Code in plain English, and it will check what is wrong and fix it.
