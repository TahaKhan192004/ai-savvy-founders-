Start here

Claude Code, set up in about 10 minutes

Claude Code is the part of the Claude desktop app that works directly on files in a folder on your computer. You describe what you want in plain English. It creates, edits and organizes the files for you, and it asks before it changes anything.

You won't write code. This guide takes you from nothing to a working setup, then gives you eight ready-to-use projects you can try on day one.

YouClaude Code
Describe the result you wantReads the files in your folder, makes a plan and does the work
Approve or decline each changeAsks before it changes anything

Before you start

  • A paid Claude plan. Pro is enough.
  • A Mac or Windows computer where you can install an app.
  • About 10 minutes for setup, and an idea of one small task to try first.

The setup in one line

  1. Get the plan and the desktop app.
  2. Open the Code tab.
  3. Give it a brand-new empty folder.
  4. Teach it about you with a CLAUDE.md file.
  5. Give it a task, and read what it asks before you approve.

Step 1 · 2 minutes

Get a paid plan and the desktop app

  1. Sign in at claude.ai and check that you are on a paid plan (Pro is enough). If you are not, upgrade from the plan page.
  2. Download the Claude desktop app from claude.ai/download for Mac or Windows.
  3. Install it, open it and sign in with the same account.
Tip

You do the whole setup in the desktop app. You never need to open a terminal or type commands.

Step 2 · 1 minute

Open the Code tab

  1. At the top of the Claude app, click Code.
  2. It will ask you to choose a folder. Don't pick one yet. Read Step 3 first.
Can't see the Code tab?

Check that you are signed in on a paid plan and that the app is up to date. If it still isn't there, see Troubleshooting.

Step 3 · 2 minutes

Create the folder Claude will work in

Claude works inside one folder on your computer. Set one up for it now.

  1. On your Desktop, make a brand-new empty folder just for this. Name it something clear, like claude-workspace.
  2. In Claude Code, choose that folder when it asks.
  3. Anything you want Claude to use, such as documents, images, spreadsheets or notes, goes inside this folder.
Later

You can start more folders for new projects. Each folder gets its own CLAUDE.md (Step 4), so Claude starts every project with the right background.

Step 4 · 5 minutes

Give it context with a CLAUDE.md file

This is the step most people skip. Right now Claude knows nothing about you. CLAUDE.md is a short file in your folder that Claude reads every time you open that folder, so you only explain yourself once.

In the Code tab, type this:

Prompt
Interview me about who I am, what I'm working on and how I like things done. Then save the answers as a CLAUDE.md file in this folder.
  1. Claude asks you questions, one at a time or in a group. Answer them honestly and specifically.
  2. It writes the file and saves it in your folder. You will see CLAUDE.md appear.
  3. Open the file and read it. Ask Claude to change anything that is wrong.

What a good CLAUDE.md covers

SectionWhat to include
Who I amYour name, role and business in one or two sentences
What I sell and who I serveYour offers and your ideal client, as specifically as you can
Current projectsWhat you are working on right now
How I like things doneTone of voice, words to avoid, formatting preferences, level of detail
RulesThings Claude must always or never do, for example "never delete files" or "ask before renaming"

Example

Example CLAUDE.md
# About me
I'm Sarah, a business coach for first-time founders. I sell a 6-week group program ($1,200) and 1:1 coaching.

# My client
Founders earning under $5k a month who feel stuck on getting their first clients.

# How I like things done
- Plain, friendly language. No jargon, no hype.
- Short sentences. Never use the words "game-changer" or "unlock".
- Keep first drafts short. I'd rather refine than cut.

# Rules
- Ask before deleting or renaming any file.
- If you're missing information, ask me. Don't guess.
- Keep original files. Work on copies.
Keep it current

Update CLAUDE.md when your offers, voice or projects change. You can say: "Add this to my CLAUDE.md: [new rule]".

Step 5

Give your first task

Now it knows you. Try something small and safe first, to see how it works.

First task
Look at what's in this folder and tell me what you see. Then suggest three useful things you could do with it, based on my CLAUDE.md.

How to write a good task

  • Say the result you want, not the steps. "Make a one-page landing page for my program" beats "write some HTML".
  • Name the files you want it to use, such as "use the testimonials in testimonials.txt".
  • Say who it is for and the tone.
  • Ask it to plan first on bigger jobs: "Before you change anything, tell me your plan."
  • Refine in the same chat. "Make the headline shorter" or "use a darker colour" is enough.

Step 6

Read what it asks before you approve

Claude Code stops and asks before it changes anything. Read those requests for your first week instead of clicking yes on autopilot. That is how you learn what it is doing and catch mistakes early.

When it asks to...Ask yourself
Create a new fileIs this a file I expected? Is it inside my folder?
Edit or overwrite a fileIs this my only copy? Would I mind if it changed?
Move, rename or delete filesDid I ask for that? Do I have a backup?
Run something on your computerDo I understand what it will do? If not, ask it to explain first
If you are not sure

Don't approve. Type: "Explain in plain language what this will do and what could go wrong." Then decide.

Use case 1

Build a landing page for your offer

Turn your offer into a real web page you can open in your browser.

Put in your folder first: Your CLAUDE.md, plus any testimonials, offer details or a logo you want to use.

Prompt
Build a one-page landing page for my [offer name]. Use what's in my CLAUDE.md for the offer, audience and voice, and the testimonials in [file name] if I've added them. Include a headline, the problem, what's included, testimonials, FAQs and a clear button that links to [booking or payment link]. Save it as index.html in this folder and tell me how to open it.

What you get: An index.html file. Double-click it to see the page in your browser. Ask for changes in plain words: "make the headline bigger", "add a pricing section", "use my brand colours".

Check before you accept: Is every claim, price and testimonial real and from you? Does the button link go to the right place?

Use case 2

Sort and rename a messy folder of files

Turn a pile of "IMG_4821" and "final_v2_FINAL" into something you can find things in.

Put in your folder first: A copy of the messy files, in a subfolder called to-sort.

Prompt
Look at the files in the to-sort folder. Don't move or rename anything yet. First, show me a plan: the folders you would create, and a table of every file with its current name and its new name. Use the format YYYY-MM-DD-short-description for names. Wait for my approval before changing anything.

What you get: A plan you can read. Once you approve, the files move into folders and get clear names. If something looks wrong in the plan, say so and it will adjust before touching anything.

Check before you accept: Read the plan table. Are any files in the wrong folder? Are any names unclear? Approve only when it looks right.

Use case 3

Make your own little tool, like a quote calculator

Build a simple tool that works in the browser, with no hosting or software to buy.

Put in your folder first: Your price list or the rules you use to quote, in a text file.

Prompt
Build a simple quote calculator as a single web page. It should ask for [the inputs, for example: number of hours, type of service, rush or standard] and calculate the price using the rules in pricing.txt. Show the total and a short breakdown. Make it look clean and professional. Save it as quote-calculator.html and show me how to open it.

What you get: A working calculator in one file, quote-calculator.html, that you can open on your computer. Ask for tweaks: add a discount code, change the colours, add your logo.

Check before you accept: Test it with three real examples that you know the answers to. Do the totals match what you would quote by hand?

Use case 4

Resize a whole folder of images for Instagram

Prepare dozens of photos in one go instead of editing each one.

Put in your folder first: A copy of your images in a subfolder called images.

Prompt
Take every image in the images folder and make Instagram-ready versions without changing the originals. Create three subfolders: portrait (1080x1350), square (1080x1080) and story (1080x1920). Crop sensibly around the centre, keep the quality high, and keep the original file names. Tell me when it's done and how many images you processed.

What you get: Three new folders, each with every image resized to the right shape. Your originals stay untouched.

Check before you accept: Open a handful of results. Are faces or text cropped out? If so, ask it to crop differently for those.

Use case 5

Turn a spreadsheet into a readable report

Get a summary of your numbers without building formulas or charts yourself.

Put in your folder first: A copy of your spreadsheet exported as a CSV file, such as sales.csv.

Prompt
Read sales.csv. Give me a one-page summary: the key totals, how this month compares with last month, my top five [products or clients], and anything that looks unusual. Then save it as report.html with a simple chart for the main trend. Don't change the CSV. If a figure is unclear, say so instead of guessing.

What you get: A report.html page you can open, with the summary and a chart.

Check before you accept: Recalculate two or three figures yourself from the spreadsheet. If they don't match, tell Claude which and ask it to explain.

Use case 6

Turn transcripts into a batch of posts

Turn one recording into a week of content.

Put in your folder first: A transcript saved as a text file, for example transcript.txt. Your CLAUDE.md should include your voice and banned words.

Prompt
Read transcript.txt. Pull out the five strongest ideas, each with one memorable line from the transcript. Then write, in my voice from CLAUDE.md: one LinkedIn post, three short-video scripts and one email newsletter section. Save each as its own file in a folder called content, and only use stories and facts that are in the transcript.

What you get: A content folder with each piece as its own file, ready to edit and post yourself.

Check before you accept: Does each piece sound like you? Are all stories and numbers actually from the transcript? Edit anything that doesn't sound right.

Use case 7

Draft client proposals from your template

Get a first draft of a proposal in minutes instead of an hour.

Put in your folder first: Your proposal template or one past proposal (with the client details removed), your price list, and your notes from the discovery call.

Prompt
Using proposal-template.txt, my price list in pricing.txt and my call notes in call-notes.txt, write a first-draft proposal for [client name]. Use their own words from the notes to describe their problem. Price it only from pricing.txt. If the scope isn't covered by my price list, write PRICE NEEDED instead of guessing. Put any questions you have at the top. Save it as proposal-[client].html.

What you get: A draft proposal, with open questions listed at the top. Open the HTML file in your browser and print it to PDF if you want a copy to send.

Check before you accept: Check every price and promise. Remove or confirm anything marked PRICE NEEDED. Never send it without reading it.

Use case 8

Clean up a contact list

Fix duplicates, bad formatting and missing fields in a spreadsheet of contacts.

Put in your folder first: A copy of your contact list as a CSV, such as contacts.csv. Remove anything sensitive you don't need.

Prompt
Read contacts.csv. Don't change it. Create a cleaned copy called contacts-clean.csv that fixes capitalization, trims extra spaces, standardizes phone formats and removes exact duplicates. For rows that might be duplicates but aren't exact, list them in a separate file called possible-duplicates.csv. Finish with a short summary of what you changed.

What you get: A clean copy of the list, a separate file of possible duplicates for you to decide on, and a summary of the changes.

Check before you accept: Scan the summary and a few rows. Check the possible-duplicates file by hand before deleting anything.

Step 8

Habits that keep you safe

  • One folder per project, each with its own CLAUDE.md.
  • Work on copies. Keep your originals somewhere else until you are happy.
  • Ask for a plan first on anything that moves, renames or deletes files.
  • Read the approval requests instead of clicking yes without looking, especially in your first week.
  • Check the output. Claude can make mistakes. Verify numbers, prices and claims before you use them.
  • Keep secrets out. No passwords, API keys, card details or confidential client data in the folder.
  • Improve CLAUDE.md whenever you fix the same thing twice.
