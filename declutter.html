Six prompts to declutter before January

Six copy-paste prompts that clean up your desktop, folders, inbox, receipts, Google Drive and subscriptions before January. Every prompt has the same rule built in: Claude deletes nothing and moves nothing until you say yes.

#PromptWhere it runs
1Desktop and Downloads, sorted every FridayClaude desktop app, with the folders connected
2Any messy folder, restructured (6 folders max)Claude desktop app, with the folder connected
3Gmail: unanswered client emails, drafted in your voiceClaude with the Gmail connector
4Tax receipts in one tableClaude desktop app (plus Gmail if receipts are in email)
5Google Drive, reorganised in batchesClaude with the Google Drive connector
6Subscription auditAny Claude chat, with your statements attached

What you need

  • Claude desktop app (Mac or Windows) for prompts 1, 2, 4 and 6. Give Claude access to the folder you want it to work in.
  • Gmail connector for prompt 3 and Google Drive connector for prompt 5. Turn them on under Settings → Connectors.
  • Claude Code (optional) if you prefer the terminal. The steps are at the end.

How to use them

  1. Copy the prompt into a new chat.
  2. Fill in anything in [square brackets].
  3. Read Claude's plan, then reply "yes" or tell it what to change.
Before you start

Back up anything you can't lose (Time Machine, OneDrive, or a copy on an external drive). Start with one small folder to see how Claude names and sorts things. Never paste passwords or full card numbers into a chat.

01

Prompt 1 of 6

Desktop and Downloads, sorted every Friday

Where: Claude desktop app, with your Desktop and Downloads folders connected.

Prompt
Tidy my Desktop and Downloads folders.

1. Look at every file and group them into simple folders by type and purpose
   (for example: Documents, Images, Screenshots, Installers, Invoices, Projects).
2. Rename messy files so the name says what it is, in this format:
   YYYY-MM-DD_short-description.ext. Keep the original extension.
3. Anything you're not sure about goes into a folder called "_Review".
   Don't guess.
4. Never delete anything. Duplicates and old installers go into
   "_Review/Possible-delete" so I can decide.

Before you move or rename a single file, show me a table:
current name | new name | destination folder.
Wait for me to say yes.

When it's done, give me a short summary: how many files moved,
how many renamed, how many are waiting in _Review.

Make it automatic: once the first run looks right, send this follow-up:

Follow-up prompt
Turn this into a scheduled task that runs every Friday at 5pm.
Use the same rules. Only move files that clearly fit an existing
folder; everything else goes to _Review. Send me the summary when it's done.
02

Prompt 2 of 6

Any messy folder, restructured (6 folders max)

Where: Claude desktop app, with the messy folder connected.

Prompt
This folder is a mess. Help me restructure it.

1. Look through everything in it, including subfolders.
2. Suggest a new structure with no more than 6 top-level folders.
   Name them so anyone could guess what's inside.
3. Show me the plan as a table:
   current path | new path | reason (one short line).
4. List anything you couldn't place in a separate "Not sure" section.

Don't move, rename or delete anything yet. Wait for me to approve
the plan or ask for changes. After I say yes, move the files and
show me the final folder tree.
Tip

If the folder is about clients or projects, add "Organise by client first, then by year" to the prompt.

03

Prompt 3 of 6

Gmail: every unanswered client email, drafted in your voice

Where: Claude with the Gmail connector turned on.

Prompt
Go through my Gmail from the last [60] days and find client emails
I never replied to.

A client email is: [describe them, e.g. anyone from a company domain
who asked a question, sent a brief, or asked about pricing or a project].
Skip newsletters, receipts, notifications and cold sales pitches.

1. List them in a table: date | sender | subject | what they need
   (one line) | how urgent (high / medium / low). Most urgent first.
2. Before writing anything, read 10 to 15 emails I've sent so you
   learn how I write: greeting, length, sign-off, how casual I am.
3. Write a reply for each one in my voice. Keep them short. If you
   need a fact you don't have (a price, a date), put [CHECK] where it goes.
4. Save each reply as a draft in Gmail. Do not send anything.

When you're done, tell me how many drafts are waiting and which
ones have a [CHECK] in them.

You then open Drafts, check each one and hit send.

04

Prompt 4 of 6

Tax receipts in one table, business vs personal

Where: Claude desktop app, with your receipts folder connected. If your receipts live in email, turn on the Gmail connector too.

Prompt
I need every receipt and invoice from [January to December 2026]
in one table for tax season.

Look in: [my Receipts folder / my Gmail / both].

1. Read each receipt or invoice (PDFs, photos, emails) and pull out:
   date | vendor | what it was for | amount | currency | business or personal
   | source file or email.
2. Business vs personal: [describe your business, e.g. "I run a design
   studio; software, equipment, coworking and client travel are business"].
   If you're not sure, mark it "Check".
3. Group it month by month with a subtotal for business and personal.
4. Flag gaps: any month with no receipts, and any regular payment
   (like a monthly tool) that's missing a receipt for a month.
5. Give me the table as a spreadsheet I can send to my accountant.

Don't move or rename any files. Just read them.
Not tax advice

This is a sorting aid, not tax advice. Your accountant decides what's deductible.

05

Prompt 5 of 6

Google Drive, reorganised in batches

Where: Claude with the Google Drive connector turned on.

Prompt
Help me reorganise my Google Drive.

1. Go through My Drive and list what's there: main folders, loose
   files in the root, and anything that looks duplicated or abandoned.
2. Suggest a new structure with no more than 6 top-level folders.
3. Give me a move map as a table:
   file or folder | current location | new location | reason.
   Split it into batches of about 25 items, most important first.
4. Wait for me to say yes before each batch.
5. After I approve a batch, move those items. If you can't move files
   with the access you have, give me that batch as a checklist I can
   drag and drop myself.

Never delete or trash anything. Leave files that are shared with me
by other people where they are.

Batches keep it reversible: if a batch looks wrong, you stop there and fix it before the next one.

06

Prompt 6 of 6

Subscription audit

Where: Any Claude chat. Download your last 3 months of bank and card statements (PDF or CSV) and attach them.

Prompt
Here are my last 3 months of bank and card statements.
Find every subscription and recurring payment I'm paying for.

1. Give me a table: service | amount | how often (monthly / yearly)
   | yearly cost | last charge date | which card or account.
   Sort by yearly cost, highest first.
2. Flag anything that looks forgotten or unused: free trials that
   turned paid, small charges I might not notice, duplicates
   (two music apps, two cloud storage plans), and prices that went up.
3. Total what I'm spending per month and per year.
4. For each one I mark "cancel", tell me where to cancel it
   (website, app store, or by email).

Don't cancel or log in to anything. Just give me the list.
Tip

Yearly plans can hide outside a 3-month window. Add a 12-month statement if you have one.

Optional

Claude Code steps (for prompts 1, 2, 4 and 6)

Prefer the terminal? Claude Code runs the same prompts on any folder on your computer.

  1. Install it. Open Terminal (Mac) or PowerShell (Windows) and follow the one-line install at docs.claude.com/en/docs/claude-code. Sign in with your Claude account when it asks.
  2. Go to the folder. For example: cd ~/Downloads
  3. Start Claude. Type claude and press Enter.
  4. Paste a prompt from this page. Claude Code asks permission before it runs a command or moves a file. Read the plan, then approve.
  5. Run it every Friday (Mac or Linux). Type crontab -e and add the line below. It only allows Claude to list, make folders and move files, so it can't delete anything.
Terminal
0 17 * * 5 cd ~/Downloads && claude -p "Sort this folder using the rules in prompt 01. Anything unclear goes to _Review. Never delete." --allowedTools "Bash(ls:*),Bash(mkdir:*),Bash(mv:*)" >> ~/declutter-log.txt

On Windows, use Task Scheduler to run the same claude -p command every Friday. If that feels like too much setup, the scheduled task in prompt 1 does the same job from the desktop app.

Safety rules and quick fixes

If something goes wrong

Before you start

  • Back up anything you can't lose (Time Machine, OneDrive, or a copy on an external drive).
  • Start with one small folder to see how Claude names and sorts things.
  • Never paste passwords or full card numbers into a chat.

Quick fixes

ProblemFix
Claude can't see my filesConnect the folder in the desktop app, or cd into it in Claude Code.
Gmail or Drive prompt says no accessTurn the connector on under Settings → Connectors and sign in again.
The plan is too detailed or too vagueReply "fewer folders" or "split Documents by year". It will redo the plan.
Drafts don't sound like meReply "read 10 more of my sent emails and rewrite them shorter and more casual".
A file ended up in the wrong placeAsk "move [file] back to where it was". Claude keeps the old path in its plan table.

Remember

Claude shows the plan first. Nothing is moved or deleted until you say yes.
