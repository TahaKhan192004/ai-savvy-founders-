Overview

Why a quiz sells

The short answer

A product quiz asks seven tap-to-answer questions, recommends one product with a backup, explains the match in the shopper's own words, and saves every answer with their email. You build it by running eight prompts in Claude Code, in order, and checking each result before the next.

Shoppers rarely leave because they dislike your brand. They leave because they cannot tell which product is right for them, so they keep scrolling.

What two brands report from their quizzes
BrandWhat they reportSource
Bambu Earth (skincare) Over $10M a year in sales. $300K to $350K a month on ads, and 100% of that ad traffic goes to their quiz, not a product page. Octane AI case study
Polysleep (mattresses) Shoppers who complete the quiz convert 6x more than shoppers who do not. Octane AI case study

Both brands built theirs on a quiz platform. This SOP shows you how to build your own version with Claude Code.

Who this is for

  • Founders and operators of online stores with a product catalogue
  • Teams who want one quiz that powers the site, the emails and the ads

What you need

  • Claude Code (terminal, desktop app, or claude.ai/code)
  • Your product catalogue, reviews, FAQs and brand details
  • An email platform such as Klaviyo, and a store such as Shopify
Note

Run the prompts in order. Wait for each one to finish and check its work before you paste the next.

Prepare

1

Install Claude Code

  1. Open the official Claude Code setup guide. Claude Code overview and setupdocs.claude.com/en/docs/claude-code/overview
  2. Follow the install steps for your computer.
  3. If you would rather not use a terminal, use the Claude desktop app, or open the web version. Claude Code on the webclaude.ai/code
  4. Confirm Claude Code opens and replies to a short test message.
2

Prepare the folder

Claude Code can only recommend what it knows about your products, so the quality of your quiz comes down to what you put in this folder.

  1. Create a new folder called product-quiz
  2. Add these five files to it:
    FileWhat goes in it
    catalogue.csvEvery product with name, price, URL, image URL and a one-line description. In Shopify, export it from Products, then Export.
    reviews.txt30 to 50 real customer reviews, copied in exactly as they were written.
    faqs.txtYour FAQ page and any return or shipping questions.
    pre-purchase-questions.txtThe questions people DM or email you before they buy, word for word.
    brand.txtYour fonts, hex colours, logo file name and two or three websites whose look you like.
  3. Check that the reviews and questions are in your customers' own words, not tidied up.
  4. Open the product-quiz folder in Claude Code.
Important

Thin files give you a generic quiz. Real reviews and real pre-purchase questions are what make the questions and the results sound like your shoppers.

Plan

3

Match products to problems

Prompts 1 and 2 do the thinking before any code gets written. The quiz is only as good as these matches.

  1. Paste Prompt 1 into Claude Code.
    Prompt 1
    Read every file in this folder: catalogue.csv, reviews.txt, faqs.txt, pre-purchase-questions.txt and brand.txt.

Match every product in my catalogue to the problem it solves for a customer. For each product, give me:
- the main problem it solves, in the customer's own words from the reviews and DMs
- who it's best for and who it's not for
- what makes it different from the closest product in my range

Save this as product-map.md. Flag any product where you don't have enough information, and tell me what you need.
  2. Wait for it to finish and save product-map.md
  3. Open the file and read the match for every product yourself.
  4. For each product Claude Code flagged, add the missing detail to your files and ask it to update the map.
4

Design the seven questions

  1. Paste Prompt 2 into Claude Code.
    Prompt 2
    Using product-map.md, build a seven-question quiz that finds the customer's main problem, what they want instead, and the one product I should recommend.

Rules:
- Question 1 is easy to answer and makes the purpose of the quiz clear
- Use the customer's language from the reviews and DMs, not my marketing language
- Every question needs 2 to 5 tap answers, no typing
- Later questions can change based on earlier answers. Map which answer leads to which question
- Every possible path must end on exactly one product, with a backup pick
- Ask for an email after the last question, before the results

Save this as quiz-logic.json and show me the full question flow as a simple list so I can check it before you build anything.
  2. Wait for it to save quiz-logic.json and show the question flow.
  3. Check the flow list against these points:
    • Question 1 is easy to answer and shows what the quiz is for
    • The wording sounds like your customers, not your marketing
    • Every question has 2 to 5 tap answers and nothing to type
    • Every path ends on exactly one product with a backup pick
    • The email step sits after the last question and before the results
  4. Ask for changes until the flow is right. Do not move on until you approve it.

Build

5

Build the quiz

Now Claude Code turns the plan into a working quiz you can open on your phone.

  1. Paste Prompt 3 into Claude Code.
    Prompt 3
    Build the quiz from quiz-logic.json as a single web page I can open in a browser.

I want:
- one question per screen, with tap-to-answer cards
- a progress bar that fills as they go
- a back button
- questions that change based on what they picked, following quiz-logic.json exactly
- an email step before the results, with a clear line on what they get in return
- fast loading and designed for a phone first

Run it locally and give me the link so I can test it on my phone.
  2. Open the local link on your phone.
  3. Take the quiz once and confirm each of these works:
    • One question per screen with tap-to-answer cards
    • The progress bar fills as you go
    • The back button returns you to the previous question
    • Different answers lead to different next questions
    • The email step appears before the results
6

Build the results page

  1. Paste Prompt 4 into Claude Code.
    Prompt 4
    Build the results page. For the recommended product show:
- the product image, name, price and an Add to cart button linking to its product page
- a "Why this fits you" section that repeats their own answers back to them in plain words, for example "You said your dog won't touch dry food, so..."
- 2 or 3 short reviews from reviews.txt from customers with the same problem
- the backup pick underneath, with one line on when to choose it instead
- answers to the 3 most common questions from faqs.txt

Use their first name if they gave it.
  2. Run the quiz again and reach the results page.
  3. Check the page shows the product image, name, price and an Add to cart button.
  4. Read the "Why this fits you" section and confirm it repeats your own answers back in plain words.
  5. Confirm the reviews match the problem, the backup pick has its one-line reason, and the three FAQ answers appear.
7

Style it to your brand

  1. Paste Prompt 5 into Claude Code.
    Prompt 5
    Restyle the whole quiz using brand.txt: my fonts, my colours and my logo. Make it feel premium, like the reference sites in brand.txt. Use generous spacing, smooth transitions between questions and clean product cards.

Then test it at phone width and fix anything that overlaps, wraps badly or is too small to tap.
  2. Open the quiz on your phone and go through every screen, including the results page.
  3. If something is off, tell Claude Code exactly what is wrong and ask for a fix.
  4. Repeat until it looks like your brand.
Tip

Expect two or three rounds of feedback in this step. That is normal. Specific feedback works best, for example: "too plain", "buttons look cheap", or "make the results page feel like a personal report". It keeps going until it looks like your brand.

Earn from it

8

Save every answer with the email

The quiz pays for itself after the click. Every answer tells you what a shopper cares about, so your follow-up can say exactly that.

  1. Replace the two bracketed names in Prompt 6 with your own email platform and store, then paste it into Claude Code.
    Prompt 6
    Connect the quiz so that when someone enters their email, their email and every quiz answer are saved to [Klaviyo / my email platform] as profile properties, plus the product they were matched with.

Ask me for the keys you need and tell me where to find them. Keep any private key on the server side, never in the page code.

Then tell me the simplest way to put this quiz on my [Shopify] store and link to it from my homepage and my ads.
  2. Give Claude Code the keys it asks for, using the locations it tells you.
  3. Take the quiz with a test email address.
  4. Open your email platform and confirm the test profile shows the email, every answer and the matched product.
  5. Follow the embed route Claude Code gives you to put the quiz on your store.
  6. Link the quiz from your homepage, your main menu and your ads.
Warning

Private keys stay on the server side. They must never appear in the page code.

9

Write the follow-up emails

  1. Paste Prompt 7 into Claude Code.
    Prompt 7
    Write a 3-email follow-up for people who took the quiz but didn't buy. Use their saved answers in every email. Never send a generic "come back and shop" message.

Email 1 (1 hour later): their match, and why it fits, using their own words. Example: "You told us your dog won't touch dry food. Here's the one picky eaters actually finish."
Email 2 (1 day later): reviews from customers who had the same problem.
Email 3 (3 days later): answer the main worry for their answers, using faqs.txt.

Give me one version per product match and tell me which properties to use for personalisation.
  2. Read the output and confirm there is one version of the sequence per product match.
  3. Confirm every email uses the shopper's saved answers and none reads like a generic "come back and shop" message.
  4. Note the list of properties Claude Code gives you for personalisation.
  5. Build the three emails in your email platform with the timing from the prompt: 1 hour, 1 day and 3 days after the quiz.
EmailSentWhat it does
11 hour laterNames their match and why it fits, in their own words
21 day laterShows reviews from customers who had the same problem
33 days laterAnswers the main worry for their answers, using faqs.txt
10

Turn answers into ad angles

  1. Export the quiz answers from your email platform.
  2. Paste Prompt 8 into Claude Code, then paste your exported answers underneath it.
    Prompt 8
    I'll paste an export of quiz answers below. Group the answers into the 5 most common problems people came with. For each one, write:
- a scroll-stopping first line for an ad, in the customer's words
- the product to show
- which quiz answer the ad should speak to

Every ad still sends people to the quiz, not a product page.
  3. Review the five problem groups and the ad line for each.
  4. Set every ad to send people to the quiz, not a product page.

FAQs

Common questions

What is a product quiz?

A product quiz is a short set of tap-to-answer questions that finds a shopper's main problem and recommends the one product that fits. It asks for an email before showing the result.

How many questions should the quiz have?

Seven. Each has 2 to 5 tap answers and no typing. Later questions can change based on earlier answers, and every path ends on exactly one product with a backup pick.

Do I need to know how to code?

No. Claude Code writes the quiz from your prompts. If you prefer not to use a terminal, use the Claude desktop app or the web version at claude.ai/code.

What files does Claude Code need?

Five files in a folder called product-quiz: catalogue.csv, reviews.txt with 30 to 50 real reviews, faqs.txt, pre-purchase-questions.txt and brand.txt.

Where should my ads send people?

To the quiz, not a product page. Bambu Earth reports that 100% of its ad traffic goes to its quiz.

How do I know the quiz is working?

Compare how many people start the quiz with how many finish it after the first week. Ask Claude Code to rewrite the question where people drop off.

Troubleshooting

When something is off

ProblemFix
Claude Code flags a product as missing informationAdd the missing detail to catalogue.csv, reviews.txt or faqs.txt, then ask it to update product-map.md.
The questions sound like marketing copyCheck that reviews.txt and pre-purchase-questions.txt hold real customer wording, then ask Claude Code to rewrite the questions in that language.
A path ends on the wrong productGo back to quiz-logic.json and ask Claude Code to fix that path so it ends on one product with a backup pick.
The quiz looks plain or cheapGive specific feedback, such as "too plain" or "buttons look cheap", and repeat until it matches brand.txt.
Elements overlap or are too small to tap on a phoneAsk Claude Code to test at phone width again and fix anything that overlaps, wraps badly or is too small to tap.
Test email does not appear in your email platformRe-run Prompt 6, confirm the keys are correct, and take the quiz again with a fresh test address.
Many people start but few finishFind the question where they drop off and ask Claude Code to rewrite it.
