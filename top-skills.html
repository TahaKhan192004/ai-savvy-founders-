Procedure

How to install any skill on this list

Use this procedure for every skill below. Each repo README has the final word, so open it first.

1

Open the repo and read the README

Click the source link on the skill's card below. Scroll to the install section and note which agents it supports (Claude Code, Claude.ai, Codex or all three).

2

Clone the repo

Open your terminal and run this, replacing the URL with the skill's link.

bash
git clone https://github.com/OWNER/REPO.git
cd REPO
3

Find the folder with the SKILL.md file

That folder is the skill. Some repos hold one skill at the root. Others hold many skills in a skills/ folder. List them with:

bash
find . -name "SKILL.md"
4

Copy it into the right place

  1. Claude Code, every project: copy the skill folder into ~/.claude/skills/
  2. Claude Code, one project only: copy it into .claude/skills/ inside that project
  3. Claude.ai: zip the skill folder, then go to Settings and upload it under Capabilities
  4. Codex: follow the Codex section of the repo README, since the folder location depends on your Codex version
bash
mkdir -p ~/.claude/skills
cp -r ./path/to/skill-folder ~/.claude/skills/
5

Restart and test it

  1. Close and reopen your Claude Code or Codex session
  2. Ask for a task the skill covers, using words from its description
  3. Check that the agent mentions or uses the skill in its reply

Important

A skill can run scripts on your machine. Read the SKILL.md and any script files before you install a repo you have not used before.

Troubleshooting

If a skill does not load

ProblemFix
The agent ignores the skillCheck the folder sits directly inside the skills folder and contains SKILL.md at its top level. Restart the session.
The skill loads for the wrong tasksOpen SKILL.md and narrow the description line at the top. The agent decides when to load a skill from that line.
Claude.ai upload failsZip the skill folder itself, not the whole repo. SKILL.md must be inside the top folder of the zip.
Two skills clashRemove one, or name the skill you want in your prompt, such as "use Taste Skill for this page".
Skill is out of dateRun git pull in the cloned repo, then copy the folder over again.

FAQs

Questions answered

What is a Claude skill?

A Claude skill is a folder with a SKILL.md file that gives Claude instructions, scripts and reference files for one kind of task. Claude reads the short description of every installed skill and loads the full skill only when a task matches it.

Do these skills work in Codex as well as Claude?

Many of them do, because the SKILL.md format is plain Markdown. Each repo README says which agents it supports, so check it before installing.

Which skill should I install first?

If you write code with an agent, start with Matt Pocock Skills or Addy Osmani Skills. If you build interfaces, start with UI UX Pro Max, Taste Skill or Impeccable.

Can I install all 11 at once?

Yes. Skills only load when a task matches their description, so having many installed costs very little context. Install the ones that match the work you actually do.
