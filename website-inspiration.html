Quick answer

Use Land-book and Pricing Pages to plan structure, Godly and Awwwards to set the look, 21st.dev, shadcn/ui blocks and Component Gallery to build parts, and Magic UI, Aceternity UI and Codrops to add motion. Give Claude one to three references per page, tell it to take structure only, and apply your brand rules every time.

Purpose Turn a design reference into an on-brand page with Claude, using ten curated sources and tested prompts.
Who this is for Founders and team members who brief Claude to build landing pages, sales pages, resource pages, and web components.
Tools needed Claude (chat, Project, or Claude Code), a web browser, a screenshot tool, and your brand rules block from Step 5.

02

Match the source to your project stage

The right source depends on where the page is in its life, not on which site looks best.

  1. Write one sentence on what the page must do, for example: "Get a founder to book a call."
  2. Find your current stage in the table below.
  3. Pick one source from that row.
  4. Add a second source only if the first leaves a gap.
StageUseWhy
Plan the structureLand-book, Pricing PagesShows section order before you design anything
Set the lookGodly, AwwwardsGives a visual direction that does not read as a template
Build the parts21st.dev, shadcn/ui blocks, Component GalleryReal code and real conventions replace guesswork
Add motionMagic UI, Aceternity UI, CodropsAdds polish after the page already works
Warning

Awwwards is useful for ambition but too heavy to copy as is. Take one idea from it, never the whole page. Add motion last, so a slow page never hides a weak structure.

04

Collect your reference

Claude works best when you give it more than a link. Gather three things: the URL, a screenshot, and code where the source offers it.

  1. Open your chosen source and find one example close to what you need.
  2. Copy the page URL from the address bar.
  3. Take a screenshot of the example. On Windows press Win + Shift + S. On Mac press Cmd + Shift + 4.
  4. For code sources (21st.dev, Magic UI, Aceternity UI, shadcn/ui blocks, Codrops), click the copy or code button and keep the code in a text file.
  5. Write one line on what you like about the example, such as "the spacing between sections."
  6. Send the extraction prompt below to Claude with your screenshot attached.
Prompt: extract a design brief
Look at this reference: [URL OR ATTACHED SCREENSHOT].
What I like about it: [YOUR ONE LINE].

Write a design brief from it using these headings:
1. Section order, top to bottom
2. Layout and spacing rules
3. Type hierarchy
4. Interaction and motion
5. Why it works for its audience
6. What I should not copy

Keep each heading to 3 lines at most. Do not suggest any colours or fonts from the reference.
Tip

Claude can read a public page only when web access is on in your session. If it says it cannot open the link, attach the screenshot or paste the code. The result is just as good.

Important

A reference is for structure, spacing, and interaction patterns. Never copy another site's text, images, colours, fonts, or branding into your page.

05

Brief Claude with the master prompt

Two prompts do the heavy lifting: your brand rules, saved once, and the master prompt, sent for every page.

  1. Open a Claude Project for your website work, or start a new chat.
  2. Paste the brand rules block below into the Project instructions. In a plain chat, paste it as your first message.
  3. Paste the master prompt into a new message.
  4. Replace every highlighted bracket with your own details.
  5. Attach your screenshot or paste your code.
  6. Send it. Claude will list what it plans to take from the reference before it builds.
  7. Read the list. If a takeaway is wrong, correct it before saying "build."

Brand rules block (save once)

Prompt: brand rules
BRAND RULES (apply to everything you build for me)
Colours: page background #FFF9F1, text #271512, accent #7A1F2B (buttons, step numbers, and small labels only), dark sections #3A211D, borders #E8DBD1, soft fills #F3E9DF and #F8E8DC.
Fonts: Newsreader for headlines, with the key verb in italic. Manrope for everything else. Body text is Manrope Light 300 at 17px, labels are Manrope Medium 500.
Shape: pill-shaped buttons, rounded cards, quiet shadows.
Never use: cool greys, emojis, em dashes, neon or futuristic AI imagery.
Icons: inline SVG only.
Brand name in any visible text: AI Savvy Founders.
Output: one self-contained HTML file with inline CSS and JS, mobile responsive at 1024px, 768px, and 480px, with basic SEO meta tags and a clean heading order.

Master prompt (send for every page)

Prompt: master brief
You are my web designer and front-end developer.

PROJECT
Page: [WHAT YOU ARE BUILDING, e.g. landing page for my AI automation audit]
Audience: [WHO IT IS FOR]
One action the page must drive: [E.G. BOOK A CALL]

REFERENCE
Source: [SOURCE NAME]
Link, screenshot, or code: [URL, ATTACHED SCREENSHOT, OR PASTED CODE]

WHAT TO TAKE
Take the structure, spacing logic, and interaction pattern. Do not copy its colours, fonts, copy, images, or brand details. Apply my brand rules.

BEFORE YOU BUILD
Tell me in 5 short bullets exactly what you are taking from the reference. Wait for my reply, then build.
Tip

The highlighted brackets in every prompt on this page are the parts you replace. Everything else stays as written.

07

Combine two or three sources in one build

Bigger pages need more than one reference. Keep it to three and name exactly what you take from each.

  1. Choose one source per stage: structure, look or component, and motion.
  2. Write down the one thing you take from each, for example "section order" or "hero effect."
  3. Copy the combination prompt below and fill in the brackets.
  4. Check the section table Claude returns before you approve the build.
  5. If the page feels busy, remove one source and run the prompt again.
Prompt: combine sources
I am combining three references for one page: [PAGE NAME].

Structure from [SOURCE 1, e.g. Land-book]: [URL OR SCREENSHOT]
Take only: section order and spacing.

Component or look from [SOURCE 2, e.g. shadcn/ui blocks]: [CODE OR URL]
Take only: [WHAT YOU TAKE].

Motion from [SOURCE 3, e.g. Aceternity UI]: [CODE OR URL]
Take only: [WHAT YOU TAKE].

Build one page with my brand rules. If two ideas clash, keep the structure and drop the effect. Before you build, show me the section list in one short table with the source each section comes from.
Warning

Do not stack two effect libraries on one screen. Magic UI plus Aceternity UI works when each effect sits in a different section, with no more than one animated element visible at a time.

08

Review the output against your brand

Claude can check its own work, but you make the final call. Run the review prompt, then test the page yourself.

  1. Open the HTML file Claude built in your browser.
  2. Narrow the window to about 375px wide and scroll the whole page. Nothing should scroll sideways.
  3. Send the review prompt below in the same chat.
  4. Read the pass or fail list and the corrected file.
  5. Tick through the publish checklist at the end of this step.
  6. Save the final file with a kebab-case name, for example landing-ai-audit.html.
Prompt: brand review
Review the page you just built against this checklist and fix anything that fails:

1. It uses only my brand colours and fonts.
2. The accent colour appears only where my rules allow.
3. There are no emojis, no em dashes, and no cool greys.
4. Nothing scrolls sideways at 375px wide.
5. Every button and link has a visible focus state.
6. Headings are in order and every image has alt text.
7. No text, image, or branding is copied from the reference.
8. The page title, meta description, and one h1 are present.

Reply with pass or fail for each line, then give me the corrected file.

Publish checklist

The reference was used for structure only, with no copied words or images.
Colours and fonts match the brand rules block.
The page passes the 375px mobile test with no sideways scroll.
Animations stop when reduced motion is on.
Focus states, heading order, and alt text are in place.
Title, meta description, and canonical link are present.
The final file is saved with a clear kebab-case name.

Troubleshooting

When the result is not right

ProblemFix
Claude cannot open the URLAttach a screenshot, or paste the visible text and the code from the source.
The page looks like the reference, not like youAdd "take structure only" to the prompt and paste the brand rules block again.
The component needs React or TailwindAsk Claude to convert it to plain HTML, CSS, and vanilla JavaScript and list what it removed.
The page feels heavy or slowAsk Claude to remove all but one animated element per screen.

FAQs

Common questions

Which design inspiration sites work best with Claude?

Land-book and Pricing Pages are best for page structure. Godly and Awwwards are best for visual direction. 21st.dev, shadcn/ui blocks, and Component Gallery are best for building components. Magic UI, Aceternity UI, and Codrops are best for motion and effects.

Can Claude open these websites?

Claude can read public pages when web access is available in your session. If it cannot open a page, attach a screenshot or paste the component code directly into the chat.

Is it acceptable to copy a design I find on these sites?

No. Use a reference for its structure, spacing, and interaction pattern. Do not copy its text, images, colours, fonts, or branding. Tell Claude to apply your own brand rules every time.

How many references should I give Claude for one page?

Use one to three references per page and name exactly what to take from each. More than three tends to produce a page that feels busy and loads slowly.

Which of the 10 sources provide code?

21st.dev, Magic UI, Aceternity UI, shadcn/ui blocks, and Codrops provide code. Land-book, Godly, Awwwards, Pricing Pages, and Component Gallery are visual or reference sources.
