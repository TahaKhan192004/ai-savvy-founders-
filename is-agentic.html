The short version

What this tool tells you

Is Agentic is a free tool from Vercel that scans a public website and returns an agent readiness score out of 100.

It lists every issue it finds, shows the evidence behind each one, and writes a prompt you can paste into Claude or Codex to fix them. This matters because an agent asked to compare products or find a service like yours can only use what it manages to reach on your site.

Before you start

What you need

  • The public address of your website, for example https://yourdomain.com
  • Edit access to your site, or a developer who can make changes for you
  • A Claude or Codex account for the fix step
01

Open the tool

  1. Open the Is Agentic homepage in your browser.
  2. Find the Website URL field under the heading Score how agentic your site is.
  3. Optional: open a featured report such as vercel.com first, so you know what a finished report looks like.
Is Agentichttps://is-agentic.com/ Sample reporthttps://is-agentic.com/scan/vercel.com
02

Enter your URL and scan

  1. Type your homepage address into the Website URL field.
  2. Submit the scan.
  3. Wait for the report to finish. Every scan is run by Ora, the engine behind the tool.
Tip

Scan your root domain first. The scanner picks a view for your site type (documentation and content, business, app, or commerce) and changes which checks are required for that type.

Note

Ora can return a complete result from a six hour freshness cache. If you scanned recently, the report you see may be a saved snapshot.

03

Read your score

  1. Write down your overall score out of 100.
  2. Note which group each failed check sits in: Essential, Recommended, or Bonus.
  3. Ignore checks marked not applicable. They are excluded from the score and never count against you.
GroupPointsWhat it covers
Essential80Baseline checks every agent needs to read and use a page.
Recommended20Checks that activate only when the scan finds an API, OAuth flow, GraphQL endpoint, MCP server, developer portal, or commerce surface.

04

Fix the Essential failures first

Essential checks carry most of the score. They cover server rendered content, correct HTTP behavior, clear document structure, recoverable errors, usable controls, and the identity metadata agents use for citations and previews.

  1. Open each failed Essential check in the report.
  2. Read the evidence line. It shows what the scanner observed on your site.
  3. Read the recommendation under it.
  4. Note the estimated gain when one is shown. It is a directional guide and not a promise.
  5. Add identity metadata if those checks failed. Copy the snippet below into the head of your page and replace the placeholder values with your own.
HTML 
<html lang="en">
<head>
  <link rel="canonical" href="https://yourdomain.com/">
  <meta property="og:title" content="Your page title">
  <meta property="og:description" content="One sentence about this page.">
  <meta property="og:image" content="https://yourdomain.com/share-image.png">
  <meta property="og:url" content="https://yourdomain.com/">
</head>
Important

Server rendered content means your main text sits in the HTML the server sends, not only in content a script builds afterwards. If that check fails, ask your developer or your site builder how to turn on server rendering for your key pages.

05

Review the Recommended gaps

  1. Check which surfaces the scanner detected on your site, such as an API, OAuth flow, GraphQL endpoint, MCP server, developer portal, or commerce pages.
  2. Fix the gaps that match what your business actually offers.
  3. Leave the rest alone. A public website is not penalized for skipping an interface it does not provide.
  4. Optional: declare your site type with a meta tag. The scanner uses a valid declaration to pick its default view. Check the docs for the accepted values.
HTML 
<meta name="is-agentic-site-type" content="business">
Is Agentic docshttps://is-agentic.com/docs
06

Read the observed agent journey

  1. Scroll to the observed agent journey section of your report.
  2. Read how one agent moved through your site.
  3. Note each point where the agent met friction.
  4. Match those points to the failed checks from steps 4 and 5.
Important

The journey is supporting evidence and sits outside the numeric score. One task cannot represent every agent, every goal, or every production condition.

07

Copy the fix prompt into Claude

  1. Click Prompt to fix in your report. It turns every actionable recommendation into one implementation brief.
  2. Copy the brief.
  3. Open Claude or Codex with access to your site code. In a plain chat, paste your page HTML along with the brief.
  4. Paste the wrapper prompt below and add the brief where it says.
  5. Read every proposed change before you apply it.
Prompt 
I want to improve how readable my website is to AI agents. Below is an implementation brief from the Is Agentic scanner.

Work through the Essential issues first, then the Recommended ones. For each change, show me the file, the exact edit, and the reason for it. Keep my visible design and copy as they are unless a fix requires a change. If a recommendation does not apply to my site, say so and skip it.

Brief:
[paste the Prompt to fix output here]
Warning

Automated checks can produce false positives and partial results. Review the evidence in context and test changes on a staging copy before you publish them.

08

Publish and rescan

  1. Publish your fixes to the live site.
  2. Return to Is Agentic and enter the same URL again.
  3. Wait for the fresh report. A rescan replaces your latest report and keeps the same shareable address.
  4. Compare the new score with the one you wrote down in step 3.
  5. Repeat steps 4 to 8 until every Essential check passes.
Note

If the score has not moved right after you publish, the tool may have served a cached result. Wait a while and scan again.

09

Share the report

  1. Copy the report address from your browser. It follows this pattern:
URL 
https://is-agentic.com/scan/yourdomain.com
  1. Send it to your developer, team, or client.
  2. Agents and developers can also read completed reports through the public JSON API or the Is Agentic MCP server. The docs list the endpoints.

Keep in mind

What a scan can and cannot see

The scan seesThe scan does not see
Public pages at one moment in timePrivate pages and logged in workflows
Status codes, crawler policies, and rendered contentUser specific state and geographic differences
Advertised APIs and emerging agent formatsBot defenses and temporary outages that appear later

A high score is a prioritized technical review. It is not a security, accessibility, privacy, or legal compliance certification.

Questions

Frequently asked questions

What is Is Agentic?

Is Agentic is a free tool from Vercel that scores how ready a public website is for AI agents. It gives a score out of 100, lists every issue with the evidence it observed, and produces a prompt you can take into Claude or Codex.

What does the score measure?

It measures what agents can discover, access, and use on the public parts of your site. Essential checks share 80 points, Recommended checks share 20 points, and emerging signals can add up to 5 bonus points.

Will my score drop if my site has no API?

No. Checks that do not apply to your site are excluded instead of counted as failures. API, OAuth, MCP, and GraphQL checks activate only when the scan positively identifies that surface.

Can it scan pages behind a login?

No. The scan observes public behavior at a point in time. Private pages, authenticated workflows, and user specific state are outside what it can see.

Does a high score guarantee agents will complete tasks on my site?

No. The report is a prioritized technical review. No score can promise that every model or browser automation system will finish every task.

How do I confirm my fixes worked?

Publish the changes and rescan the same public URL. The new scan replaces the latest report with a fresh snapshot at the same address. Results can come from a six hour cache, so wait and rescan if the score has not moved.
