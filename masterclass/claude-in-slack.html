Set up and run Claude Tag in Slack

A complete procedure for pairing Claude Tag with your Slack workspace, scoping its access, setting spend limits, and getting your team tagging @Claude with confidence.

Purpose

This procedure walks a Slack workspace administrator through standing up Claude Tag, Anthropic's team-based way of working with Claude inside Slack. Claude joins as a team member that anyone in a channel can tag with @Claude, delegate tasks to, and collaborate with asynchronously.

Who this is for

Workspace administrators or IT leads on a Claude Enterprise or Team plan who are responsible for provisioning Claude Tag, scoping its data access, and rolling it out to their organization.

Tools needed

  • A Claude Enterprise or Team account
  • Admin permissions on the target Slack workspace
  • A list of the tools, data sources, and codebases Claude should connect to
  • A private Slack channel to use for testing
Note

Claude Tag runs on Opus 4.8 and replaces the existing Claude in Slack app. Existing installations are not migrated automatically, administrators must opt in within a 30 day window.

01

Confirm eligibility

Claude Tag is available in beta to Claude Enterprise and Team customers. Confirm your plan before starting setup so you are not blocked partway through.

  1. Check your current Claude plan under your organization's billing or account settings.
  2. If you are not currently on Enterprise or Team, contact your Anthropic account representative or sales to upgrade before continuing.
  3. Confirm you have administrator permissions on the Slack workspace you intend to connect, since pairing requires workspace-level approval.
02

Pair Claude Tag with your Slack workspace

Pairing connects your Slack workspace to your Claude organization so Claude can be invited into channels.

  1. Open the Claude Tag admin settings page from your Claude Enterprise or Team dashboard.
  2. Select Pair with Slack and choose the workspace you want to connect.
  3. Approve the requested Slack permissions when prompted. These permissions let Claude read and post in the channels it is later invited to.
  4. Confirm the pairing shows as Connected on the admin settings page before moving to the next step.

03

Grant tool and channel access

This step defines what Claude can see and do. Treat each channel as its own scoped identity, memories and tool access do not cross between channels.

  1. From the admin settings page, select the channels you want Claude Tag to operate in.
  2. For each channel, choose which tools, data sources, and codebases Claude should be able to access while working there.
  3. Keep sensitive data scoped narrowly. A channel set up for sales should not also carry engineering tools or codebases, and the reverse is true as well.
  4. Decide whether to enable ambient behavior for each channel. With it on, Claude proactively flags relevant updates and follows up on stalled threads without being tagged first.
  5. Save your access configuration.
Important

Claude does not report information from private channels into channels it learns from automatically. It only surfaces information from channels and sources an administrator has explicitly granted it access to.

04

Set a limit on monthly spend

Spend limits give you a budget ceiling at two levels, the organization as a whole and individual channels, so usage cannot run away unnoticed.

  1. In the admin settings page, locate the Spend limits section.
  2. Set an organization-wide monthly token spend cap.
  3. Optionally set tighter per-channel limits for high-traffic or experimental channels.
  4. Save your limits. You can revisit and adjust these at any time as usage patterns become clearer.
05

Test Claude in a private channel

Always confirm the setup works in a low-stakes channel before rolling it out to the wider team.

  1. Create or choose a private Slack channel for testing.
  2. Invite Claude into the channel the same way you would invite a teammate.
  3. Tag @Claude with a simple, low-risk request to confirm it responds correctly and has access to the tools you configured.
  4. Review the response in the thread and confirm Claude used only the tools and data sources you intended to grant.
  5. Once confirmed, the channel is ready for production use, or you can invite Claude into your real working channels.
Tip

Within a channel, there is one shared Claude for everyone. Anyone can pick up a task where the last person left off, so it is worth testing this handoff behavior with a second teammate before a full rollout.

06

Migrate from Claude in Slack

Claude Tag replaces the existing Claude in Slack app. If your organization already uses it, migration is opt-in rather than automatic.

  1. Check whether your workspace currently has the Claude in Slack app installed.
  2. If it does, opt in to migration from the Claude Tag admin settings page within 30 days of setting up Claude Tag.
  3. Check your eligibility for the introductory launch credit issued to qualifying Enterprise and Team organizations, so your team can try Claude Tag at no additional cost during rollout.
Warning

The 30 day migration window starts from setup, not from your renewal date. Mark this on your calendar so the opt-in is not missed.

07

Roll out to your team

Once testing confirms the setup, open Claude Tag up to the rest of the channel and start using it day to day.

  1. Announce Claude Tag in each relevant channel so teammates know it is available and what it has access to.
  2. Share a couple of example requests so the team sees how to phrase a task for @Claude.
  3. Encourage teammates to tag Claude for things like chasing down product metrics, working through support tickets, or finding the root cause of a bug.
  4. Remind the team that direct messages to Claude are answered privately, using each person's own connected tools.
  5. Review the admin activity log periodically to see what Claude has worked on and who requested each task.

FAQs

Does Claude remember things across different channels?

No. Memories, tools, and data access stay scoped to the channels an administrator has defined. A Claude identity set up for sales will not pass memories or access to one set up for engineering.

Can Claude work on something while my team is offline?

Yes. Claude Tag works asynchronously, it can be set a task and continue working on it over hours or days, including scheduling follow up work for itself.

Where is Claude Tag available beyond Slack?

Slack is the first surface for Claude Tag. Anthropic has stated the goal of expanding to other places teams work over time.

What model powers Claude Tag?

Claude Tag works with Opus 4.8.
