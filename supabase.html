Standard Operating Procedure

How to Build a Working Quiz With Claude Code + Supabase

A step-by-step guide for non-technical founders. No quiz software. No monthly fee. Full ownership of every answer.

30 minutes Beginner August 2026

What You Are Building

A fully functional lead-generation quiz that asks questions, scores answers, and shows a personalised results page. It captures the email before revealing results and stores every response in a Supabase database you own.

Once live, you can query the data anytime to see which questions people score lowest on, which result bucket they land in, and what patterns show up across leads.

01

Plan Your Quiz Before You Touch Claude

Before you open Claude Code, get clear on four things. Write them down in a notes app or a doc. Claude builds better when you give it a proper brief.

  1. 1. What does the quiz measure?
    One thing. Not five. Example: "How AI-ready is your business?" or "What's your content system score?"
  2. 2. Who is taking it?
    Not a demographic. A real person. Example: "A coach or consultant who knows they should be using AI but hasn't started."
  3. 3. What are the 3-4 result buckets?
    These are the categories someone can land in based on their score. Here is an example:
Starter
Score 7 - 14

Not using AI yet, lots of quick wins available

Explorer
Score 15 - 21

Dabbling but no system

Builder
Score 22 - 28

Using AI but leaving efficiency on the table

Operator
Score 29 - 35

AI is embedded in their workflow

  1. 4. What happens after the quiz?
    Where does the person go next? A free call? A masterclass? An email sequence? The quiz needs to point somewhere.
IMPORTANT

If you skip this step and go straight to Claude, you will get a generic quiz that does not convert. The brief is the work. Claude is the builder.

02

Set Up Your Supabase Account

This is your database. It is where every quiz answer lands.

  1. a. Go to supabase.com and create a free account.
  2. b. Click New Project.
  3. c. Give it a name (example: "quiz-data").
  4. d. Choose a region close to your audience.
  5. e. Set a database password and save it somewhere safe.
  6. f. Wait about 60 seconds for the project to spin up.
TIP

You do not need to create any tables manually. Claude Code will do that for you in Step 4.

03

Connect the Supabase MCP to Claude

This is what lets Claude talk directly to your database.

  1. a. Open Claude (desktop app or claude.ai).
  2. b. Go to the integrations/connectors area.
  3. c. Search for Supabase.
  4. d. Click Connect.
  5. e. Authorise your Supabase account when prompted.
  6. f. Select the project you just created.

Once connected, Claude can create tables, read data, and write to your database without you ever opening Supabase again.

04

Open Claude Code and Build the Quiz

Now you build. Open Claude Code and paste the prompt below. Replace the bracketed sections with your own quiz details from Step 1.

The Prompt

Prompt Build me a lead-generation quiz as a single-page React app with these specs: QUIZ DETAILS: - Title: [Your quiz title, e.g. "What's Your AI Readiness Score?"] - Audience: [Who is taking this, e.g. "coaches and consultants"] - Number of questions: [7-10] - Questions should mix self-assessment and scenario-based formats - Each question gets 4 answer options scored 1-4 RESULT BUCKETS: - [Bucket 1 name]: Score [range] - [one sentence description] - [Bucket 2 name]: Score [range] - [one sentence description] - [Bucket 3 name]: Score [range] - [one sentence description] - [Bucket 4 name]: Score [range] - [one sentence description] RESULTS PAGE: Each result bucket shows: - Their score out of the maximum - Their bucket name - 2-3 sentences of validation (what they are doing right) - 2-3 sentences of diagnosis (what the score reveals) - The gap (one thing keeping them from the next level) - A CTA button that links to [your next step URL] EMAIL CAPTURE: - After the last question and before showing results, ask for their email - Copy: "Enter your email to see your personalised results and recommendations" - Email field + "Get My Results" button DATA STORAGE: - Use my connected Supabase project to store all responses - Create a table called "quiz_responses" with columns for: - id (auto-generated) - email - answers (store each question and selected answer) - total_score - result_bucket - created_at (timestamp) - Every submission writes a row to this table DESIGN: - Clean, modern, mobile-first - One question per screen with a progress bar - Smooth transitions between questions - Use [your brand colours] Deploy this so I get a shareable link.

What Claude Code will do

When you paste this prompt, Claude Code will:

  1. a. Write the quiz front-end (the questions, scoring, results page).
  2. b. Connect to your Supabase project through the MCP.
  3. c. Create the quiz_responses table automatically.
  4. d. Wire up the form so every submission writes to that table.
  5. e. Deploy it and give you a live URL.
NOTE

This typically takes 2-5 minutes. Watch it work. If something looks off, tell Claude what to fix in plain language.

05

Test the Quiz

Before you share the link with anyone, run through these checks:

  1. a. Take the quiz yourself. Answer honestly and check that your result bucket feels accurate.
  2. b. Take it again with extreme answers (all lowest, all highest) to make sure edge cases work.
  3. c. Check your Supabase table. Go to supabase.com, open your project, click Table Editor on the left, and look at the quiz_responses table. Your test entries should be there.
  4. d. Try it on your phone. Open the link on mobile and go through the full flow.
TIP

If anything looks cramped or broken on mobile, tell Claude Code: "The quiz is not displaying well on mobile. Fix the responsive layout." It will handle it.

06

Use the Data

This is the part that makes owning the database worth it. Once real answers start coming in, you can ask Claude to read the table and pull insights.

See all responses

Prompt Read my quiz_responses table in Supabase and show me all entries from the last 7 days.

Find scoring patterns

Prompt Read my quiz_responses table. For each question, show me the average score and which answer option was chosen most often. I want to see where people are scoring lowest.

Segment by result bucket

Prompt Read my quiz_responses table and group responses by result_bucket. How many people landed in each bucket? Show me the breakdown as percentages.

Export for outreach

Prompt Read my quiz_responses table. Pull all emails where the result_bucket is "Starter" or "Explorer" and export them as a CSV. These are my warmest leads for [your offer].

Market research

Prompt Read my quiz_responses table. Which three questions have the lowest average scores across all responses? These are the biggest gaps in my audience. Summarise what this tells me about what they need.
07

Iterate Based on Data

Your quiz is not finished when it launches. It is finished when the data tells you it is working.

After 20-30 responses, check:

  1. a. Are people finishing the quiz or dropping off? If drop-off is high, your questions might be too long or confusing. Simplify them.
  2. b. Is one result bucket getting 80%+ of responses? Your scoring ranges might need adjusting. Rebalance them.
  3. c. Are the email capture rates decent? If people skip the email step, your results page promise might not be compelling enough.

To make changes

Open Claude Code and describe what you want in plain language:

Prompt Open my quiz project. Change question 3 to [new question]. Update the scoring so the "Explorer" bucket covers scores 12-18 instead of 15-21. Redeploy.

Claude Code will make the changes and redeploy. Same link, updated quiz.

Frequently Asked Questions

Can I add more questions later?

Yes. Open Claude Code and say "Add a new question to my quiz about [topic]. Put it after question 4. Score it the same way as the others." Claude will insert the question and redeploy.

Can I change the design?

Yes. Tell Claude Code what you want: "Change the quiz background to white, make the buttons rounded, and use my brand font [font name]." It handles the CSS and redeployment.

Can I connect this to my email tool?

Yes. If you use GoHighLevel, Mailchimp, ConvertKit, or similar, ask Claude Code to add a webhook or API call that fires when someone submits the quiz. The email gets sent to your email platform automatically.

What happens when I hit the Supabase free tier limit?

The free tier handles 50,000 rows and 500MB of storage. A single quiz response is tiny. You would need tens of thousands of quiz-takers before this matters. If you get there, Supabase Pro is $25/month.

Can I build multiple quizzes on the same Supabase project?

Yes. Create a separate table for each quiz (e.g. quiz_ai_readiness, quiz_content_score) or add a quiz_name column to one table. Ask Claude Code to set it up however you prefer.

Troubleshooting

Problem

Claude Code says it cannot connect to Supabase

Fix

Go back to your Claude integrations and confirm the Supabase MCP is connected. Make sure you selected the correct project. Disconnect and reconnect if needed.

Problem

Quiz submissions are not appearing in the Supabase table

Fix

Check the browser console for errors (right-click the page, choose "Inspect", click "Console"). The Supabase URL or anon key may not be set correctly. Ask Claude Code: "Check the Supabase connection in my quiz and fix any credential issues."

Problem

The quiz looks broken on mobile

Fix

Tell Claude Code: "The quiz is not displaying well on mobile. Fix the responsive layout so it works on screens as narrow as 375px." It will adjust the CSS and redeploy.

Problem

One result bucket gets almost all the responses

Fix

Your scoring ranges need rebalancing. Look at the actual score distribution across your responses and adjust the bucket boundaries so they split more evenly. Tell Claude Code the new ranges and redeploy.
