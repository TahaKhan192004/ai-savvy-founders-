Purpose

What this SOP does

This procedure gives your coding agent four upgrades. You never type a command. For each step you copy a plain-English instruction, paste it into your agent, and read what it reports back.

Graphify

A map of your project. Your agent reads less and finds things faster.

Ponytail

A short-code rule. Your agent writes only what is needed.

OmniRoute

A backup engine. When you hit a usage limit, work carries on with another model.

Agent Skills

A professional build process: plan first, build in small pieces, test, review, then ship.

Who this is for

  • Founders who build with an AI coding agent and do not write code by hand
  • Team members setting up a new machine or a new client project

What you need

  • Claude Code, installed and signed in
  • A project folder to work in (an existing project or an empty one)
  • An internet connection
Important

Do the steps in this order: Agent Skills, then Ponytail, then Graphify, then OmniRoute. OmniRoute needs the most setup, so it goes last.

How to use the blocks below

Each dark block is an instruction for your agent. Press Copy, paste it into Claude Code, and press enter. Then compare what the agent reports with the "What you should see" box under it.

01

Open your agent and run a readiness check

The agent checks your machine and fixes gaps before anything is installed.

  1. Open Claude Code inside your project folder.
  2. Paste this instruction:
Paste to your agent
Before we install anything, check that this computer has Node.js, Python with the uv tool, and Git.
Tell me in plain English which ones are present and which are missing.
If anything is missing, explain what it is in one sentence and ask me before you install it.
  1. Answer yes when the agent asks to install a missing tool.
What you should see

A short plain-English list saying all three tools are present, or that the agent installed the missing ones.

02

Add Agent Skills

Gives your agent a professional build process. It covers writing a spec, planning, building, testing, reviewing and shipping.

  1. Paste this instruction into your agent:
Paste to your agent
Add the Agent Skills plugin by Addy Osmani. The only source to use is the GitHub repository addyosmani/agent-skills.
Install it so I can use the commands for specs, plans, builds, tests, reviews and shipping.
When it is done, list the commands I can now use in plain English.
What you should see

A list of nine commands: /spec, /plan, /build, /test, /constraints, /review, /webperf, /code-simplify and /ship.

Tip

You do not need all nine on every job. For a new feature, the useful run is spec, plan, build, test, review, ship.

Agent Skills sourcegithub.com/addyosmani/agent-skills
03

Add Ponytail

Before writing anything, your agent asks whether the work can be skipped, reused or done in one line. It never cuts safety checks.

  1. Paste this instruction into your agent:
Paste to your agent
Add the Ponytail plugin. The only sources to trust are the GitHub repository DietrichGebert/ponytail and the npm package @dietrichgebert/ponytail. Other projects named ponytail exist, so do not use them.
Install it, turn it on, and tell me which level it is running at.
Warning

Keep the two source names in the instruction. They stop your agent installing a lookalike by mistake.

What you should see

A message saying Ponytail is installed and on, with its current level.

Useful things to ask Ponytail later

Say this to your agentWhat happens
"Run a Ponytail review of my latest changes."You get a list of extras that can be deleted
"Run a Ponytail audit of the whole project."The same check across everything, not just the latest changes
"Set Ponytail to strictest."The agent writes the least code possible
"Turn Ponytail off."Back to normal behaviour

04

Add Graphify and map your project

Builds a map of how everything in your project connects, so your agent stops rereading the same files.

  1. Make sure Claude Code is open in the project you want mapped.
  2. Paste this instruction:
Paste to your agent
Install Graphify from the GitHub repository Graphify-Labs/graphify. The Python package name is graphifyy, spelled with two y's.
Connect it to Claude Code, then build the map for this project folder.
When it finishes, open the plain-English report it created and summarise the three most important things in my project.
What you should see

A new folder called graphify-out containing an interactive map, a plain-English report and the raw data. Your agent should also give you a short summary of your project.

Tip

Ask your agent to "keep the Graphify map up to date automatically whenever I save changes to Git". Then you never have to rebuild it.

Note

The map marks each connection as read directly or guessed, so you can see how much to trust it. The project does not publish a token-saving percentage, so judge the saving on your own project.

Graphify sourcegithub.com/Graphify-Labs/graphify
05

Add OmniRoute as your backup engine

Runs on your own computer. When one AI model hits its limit or fails, work moves to the next one in your list.

  1. Paste this instruction into your agent:
Paste to your agent
Install OmniRoute from the GitHub repository diegosouzapw/OmniRoute (npm package: omniroute) and start it on this computer only.
Do not expose it to the internet.
Confirm it is running, then give me the address of its dashboard so I can open it.
  1. Open the dashboard address your agent gives you. It should end in /dashboard.
  2. Add the AI providers you already use or want to use.
  3. Put your main model first, then cheaper models, then free ones. This order is your fallback chain.
Warning: client work

OmniRoute sends your prompts and code to whichever provider handles the request. Free tiers often have different data terms than paid ones. Read the terms before routing client work through a free tier.

A cheaper or free model is also not the same as the one you started on. Fallback keeps you working, but quality can change.

What you should see

Your agent confirms OmniRoute is running locally, and the dashboard opens in your browser.

OmniRoute sourcegithub.com/diegosouzapw/OmniRoute
06

Connect Claude Code to OmniRoute

Tells Claude Code to send its work through your backup engine.

  1. Paste this instruction into your agent:
Paste to your agent
Connect Claude Code to the OmniRoute gateway I just installed, following the OmniRoute guide for Claude Code.
Use the local address on port 20128 without adding /v1 on the end, and turn on model discovery so the gateway models show up in my model list.
Tell me exactly what you changed, and tell me if I need to restart Claude Code.
  1. Restart Claude Code when your agent tells you to. The new settings load only at startup.
  2. Ask your agent to show the list of available models.
What you should see

OmniRoute models appear in your model list after the restart.

Tip

OmniRoute also has a one-step launcher. You can ask your agent: "Show me how to start Claude Code through OmniRoute each day with one action."

07

Work the new way

From now on, each plugin does its job in the background while you talk to your agent normally.

Stage of your workPlugin doing the job
Starting on an existing projectGraphify maps it so your agent does not reread everything
Planning and buildingAgent Skills supplies the spec, plan and build process
Writing the codePonytail keeps it minimal
Long working sessionsOmniRoute keeps you going when a limit hits

Your first-week routine

  1. Day one: ask your agent to map the project with Graphify.
  2. Turn Ponytail on and leave it on.
  3. For each new feature, say: "Write a spec for this feature, then a plan, then build it one small piece at a time."
  4. On days you expect to hit limits, start Claude Code through OmniRoute.
  5. Before you ship, say: "Run a Ponytail review and a full code review on what we just built."
Tip

If your project has grown fast, ask for a Ponytail audit of the whole project. It finds extras across everything, not just the latest changes.

08

Confirm everything works

Ask the agent to check its own setup, then tick each item below.

  1. Paste this instruction into your agent:
Paste to your agent
Give me a plain-English status report on the four plugins we set up: Agent Skills, Ponytail, Graphify and OmniRoute.
For each one, tell me whether it is installed, whether it is working, and prove it with one quick test.
If anything is not working, tell me what is wrong and fix it, asking me first if the fix needs my approval.
  1. Read the report and tick each item you can confirm:

All six ticked means you are set. Start your first feature by asking your agent for a spec.

Support

Frequently asked questions

Do I need to run any commands myself?

No. You paste an instruction and your agent carries it out. You only make the decisions it asks about, such as approving an install or choosing providers in the OmniRoute dashboard.

What if my agent says it cannot do a step?

Some plugin installs are typed as commands that begin with a slash. If your agent says it cannot run one, ask it to show you the exact line, then paste that line into the Claude Code message box yourself. Everything else the agent handles.

Can I use these with other coding agents?

In most cases, yes. Graphify supports Claude Code and 15+ other agents including Cursor, Codex, Gemini CLI and GitHub Copilot. Agent Skills works in Cursor, Codex, Gemini CLI and Copilot. OmniRoute serves any tool that speaks the OpenAI format. Ponytail has install options for other agents in its repository.

Does Ponytail cut my token use in half?

No. The project's own test showed about 54 percent less code and about 22 percent fewer tokens. Use "cuts code by about half" if you talk about it publicly.

Is OmniRoute safe for client work?

Only if you have read each provider's data terms. Prompts and code go to whichever provider handles the request, and free tiers often have different terms than paid ones.

How many free tokens does OmniRoute give me?

The project claims up to about 1.6 billion free tokens a month by stacking free tiers. It re-audits that figure every two weeks and it depends on each provider's terms, so treat it as an estimate.
