Start here

Give your clip a movie look with one prompt

Put your clip and a still from the movie whose look you want in a folder, open Claude Code, and paste one prompt. Claude measures the colours in the still, builds a colour grade, checks a before/after frame, then renders your graded clip.

What you get

  • A measured palette from the reference still: the 5 main colours as hex codes, plus a one-line description of the look.
  • Your full graded clip saved as my-clip_graded.mp4, at the original resolution and frame rate, with the audio kept.
  • A before/after frame, side by side, so you can see what changed.
  • A .cube LUT file you can reuse in CapCut, Premiere or DaVinci.
  • The exact ffmpeg filter Claude used, so you can run it on other clips.
The idea

Claude measures the numbers in the reference still with code instead of guessing: the average colour of the shadows, midtones and highlights, plus overall saturation and contrast. Then it moves your clip toward those numbers.

01

What you need

Before you start

  • Claude Code. It needs a paid Claude plan (Pro or Max). New to it? See the Claude Code starter guide.
  • Your clip as an mp4 or mov file.
  • A still from the movie whose look you want. A screenshot is fine.
  • ffmpeg, the free video tool Claude uses to grade. Claude installs it if it is missing.
02

The process

Four steps, start to finish

  1. Make a new folder and put your clip and the movie still in it.
  2. Open Claude Code in that folder.
  3. Paste the prompt below, with your file names and the movie filled in.
  4. Claude measures the colours in the still, shows you the palette, builds the grade, checks a before/after frame, then renders your graded clip.
Fill in three things

In the prompt, replace [my-clip.mp4] with your clip's file name, [still.jpg] with your still's file name, and [movie name] with the movie. Leave everything else as it is.

03

The prompt

Copy and paste

Prompt
Color grade my clip to match a movie look.

Clip: [my-clip.mp4]
Reference still: [still.jpg], from [movie name]


Check that ffmpeg is installed. If it isn’t, install it for me.
Measure the colours of the reference still with code, don’t guess: the average colour of the shadows, midtones and highlights, plus its overall saturation and contrast. Show me the 5 main colours as hex codes and describe the look in one short line (like “Moss green, wild bloom. Lush and storybook.”).
Build an ffmpeg colour grade that moves my clip toward those numbers: colorbalance for shadows, midtones and highlights, eq for contrast, saturation and gamma, and curves if needed. Keep skin tones natural.
Export one frame of my clip before and after, side by side. Look at it, compare it with the reference, and adjust the grade once if it’s off.
Render the full graded clip as [my-clip]_graded.mp4 at the original resolution and frame rate, keeping the audio.
Also save the grade as a .cube LUT file, so I can reuse it in CapCut, Premiere or DaVinci.
Show me the exact ffmpeg filter you used, so I can run it on other clips.

Tips for better results

  • Pick a still that shows the look clearly: a frame with a lot of the scene in it, not a close-up of one object.
  • Match the lighting where you can. A night still will pull a bright daytime clip a long way, so check the before/after frame.
  • Watch skin tones. The prompt asks Claude to keep them natural. If faces look off, ask for the grade to be softened.
  • Test on a short clip first. It renders faster and you can fix the look before grading a long video.

Troubleshooting

If something goes wrong

ProblemFix
Claude can't find my clip or stillBoth files must be in the folder you opened in Claude Code. Check the file names match what you typed in the prompt
ffmpeg won't installAsk: "That didn't work. Explain what went wrong in plain language and fix it." If it still fails, say which computer you use and ask for step-by-step install instructions
The grade looks too strongAsk for a softer version, such as half the strength, then re-render
Skin tones look wrongAsk Claude to protect skin tones more and compare the before/after frame again
The result doesn't look like the movieTry a different still that shows more of the scene, and run the prompt again
It stopped halfwayType: "That didn't finish. Explain what went wrong in plain language and fix it."
