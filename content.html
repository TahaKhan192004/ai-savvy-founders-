Content Globe Planner: your own working artifact in a few steps

Fill in a brand brief, and Claude researches Reddit, plans a month of posts, writes every caption, and can schedule the posts for you. You get it as your own private artifact by dragging in two files and pasting one prompt.

TimeAbout 10 minutes to set up
LevelBeginner
You needA Claude account that can make artifacts, and the Parallel Search connector (Composio is optional)
Works inClaude chat (claude.ai or the desktop app)

The whole thing in five steps

  1. Connect Parallel Search (for live Reddit research).
  2. Connect Composio (optional, only if you want to schedule posts).
  3. Download the two files.
  4. Drag both files into a new chat and paste the prompt.
  5. Open your artifact and allow the permissions.
What you get

A working page called "Content Globe Planner" in your own account. It is private to you until you share it.

01

Step 1

Connect Parallel Search

Parallel Search lets the planner research live Reddit threads and websites.

  1. Go to claude.ai and open Settings then Connectors.
  2. Click Browse and add Parallel Search.
  3. Sign in if it asks.
Skipping it

The planner still works without Parallel Search, but Claude brainstorms ideas without live Reddit threads.

02

Step 2

Connect Composio (optional)

Only do this if you want the Schedule posts button. If you only want to plan posts and captions, skip to Step 3.

  1. Go to Settings then Connectors then Add custom connector.
  2. Name it exactly Composio.
  3. Use the URL https://connect.composio.dev/mcp.
  4. Sign in.
  5. To schedule LinkedIn or X posts, also connect a scheduling app (Buffer, Upload-Post, Postpone or Typefully) inside Composio. Facebook Pages can be scheduled without one.
Keep the exact name

The name must be exactly Composio, and the Parallel connector must keep the name Parallel Search. The page looks for those names.

04

Step 4

Drag both files in and paste the prompt

  1. Start a new chat in Claude (claude.ai or the desktop app).
  2. Drag content-globe-planner.html and SETUP-PROMPT.md into the message box. You should see both appear as attachments.
  3. Copy the prompt below and paste it into the same message.
  4. Send it.
Prompt
I've attached content-globe-planner.html. Publish it as my own private artifact, exactly as it is, and turn on the capabilities it needs. Don't redesign, rewrite or "improve" it. The page is finished and tested.

Do these steps in order:

1. Read the attached file in full so you know what you're publishing. It is a self-contained HTML page called "Content Globe Planner". You give it a brand brief, and it calls Claude (through the artifact's own Claude access) and the user's connectors to research Reddit, plan posts, write captions, and optionally schedule posts. Make no changes to it.

2. Publish the file as a NEW artifact, unchanged, using your artifact tools.
   - Title: "Content Globe Planner"
   - Icon: "calendar"
   - If you can publish from a file on disk, publish the attached file directly as index.html. Otherwise publish its complete contents as the page. Never publish a cut-down or partial copy.

3. Turn on (declare) these capabilities for the artifact, using exactly these names. Some platforms want capabilities declared after a new page is published; follow whatever order your artifact tools require.
   {
     "sample": {},
     "mcp": { "servers": [
       { "server": "Parallel Search", "tools": ["web_search", "web_fetch"] },
       { "server": "Composio", "tools": ["COMPOSIO_SEARCH_TOOLS", "COMPOSIO_GET_TOOL_SCHEMAS", "COMPOSIO_MANAGE_CONNECTIONS", "COMPOSIO_MULTI_EXECUTE_TOOL"] }
     ]},
     "downloads": true
   }
   - "sample" lets the page ask Claude to write.
   - "Parallel Search" is for Reddit and website research.
   - "Composio" is optional and only used to schedule posts.
   - "downloads" lets the page save .md, .csv and .json exports.
   Keep the server names exactly "Parallel Search" and "Composio", because the page looks for those names. If one of my connectors has a slightly different display name, tell me and ask whether to rename the connector or change the declaration. Don't edit the page's code.

4. Check my setup and report back in a short list:
   - The link to the new artifact.
   - Whether the Parallel Search connector is connected for me. If it isn't, tell me to add it in Settings → Connectors. The page still works without it, but ideas won't come from live Reddit threads.
   - Whether a connector named "Composio" is connected. If it isn't, say that's optional and only needed for the "Schedule posts" button. Setup is: Settings → Connectors → Add custom connector, name "Composio", URL https://connect.composio.dev/mcp.
   - A reminder that the first Generate click asks me to allow the page to use Claude and Parallel Search, the first scheduling run asks for Composio, and runs use my own Claude usage.

5. Don't run the planner yourself, don't generate sample content, and don't add features. Stop after step 4.

If your tools can't do part of this (for example, you can't declare capabilities in this chat), tell me plainly which step failed and what I should do. Don't fall back to rebuilding the page from scratch.

Claude publishes the page unchanged as a new private artifact, turns on the capabilities it needs, and then reports back with the link and what is connected on your account.

Do not change the prompt

The prompt tells Claude to publish the file exactly as it is. Keep the names "Parallel Search" and "Composio" as they are.

05

Step 5

Open your artifact and allow the permissions

  1. Open the link Claude gives you at the end.
  2. The first time you click Generate, allow the page to use Claude and Parallel Search.
  3. The first time you schedule posts, allow it to use Composio.

Runs use your own Claude usage.

Using the planner

  • Fill example brief fills in a sample brand. Watch a finished demo replays a complete example without using any Claude usage.
  • A typical run of 2 weeks on 2 platforms is about 12 posts and takes roughly 3 to 5 minutes. Each run is capped at 40 posts and 31 days.
  • Click any calendar day to read, edit, copy or rewrite its posts.
  • Download .md / .csv / .json exports the whole plan.
  • Schedule posts works only if Composio is connected. You review the times, confirm, and Claude schedules through Composio. The page blocks anything that would publish immediately or delete a post.
06

Optional

Turn your plan into visuals

Already have your month of posts? Add a second artifact, Visual Studio, that designs the images for them in your brand. It opens as an empty globe and fills up after you upload your content. It needs only Claude, with no extra connectors. If you only want the plan and captions, skip this step.

You can makeFormat
Static posts and quote cardsPNG
Carousels and document slidesOne PNG per slide
Reel coversPNG, 9:16
Story framesPNG, 9:16
Good to know

Visual Studio creates designed graphics using text, shapes, layouts and your own photos. It does not generate AI photos or video.

Before you start

  • Your plan from Content Globe Planner: click Download .json (.csv also works)
  • Your logo (optional)
  • Your brand colours as you want them to appear
  • Your own photos (optional). Give them clear file names, such as me-at-desk.jpg

Step 2. Publish it

Start a new chat in Claude (claude.ai or the desktop app). Drag in visual-studio.html, paste this prompt and send it.

Visual Studio prompt
I've attached visual-studio.html. Publish it as my own private artifact, exactly as it is, and turn on the capabilities it needs. Don't redesign, rewrite or "improve" it, and don't add sample content. It is meant to open empty.

Do these steps in order:

1. Read the attached file in full so you know what you're publishing. It is a self-contained HTML page called "Visual Studio". I upload a content plan into it, and it uses Claude (through the artifact's own Claude access) to design graphics for my posts, which I can download. Make no changes to it.

2. Publish the file as a NEW artifact, unchanged, using your artifact tools.
   - Title: "Visual Studio"
   - Icon: "image"
   - If you can publish from a file on disk, publish the attached file directly. Otherwise publish its complete contents as the page. Never publish a cut-down or partial copy.

3. Turn on (declare) exactly these capabilities, using these names. Some platforms want capabilities declared after a new page is published; follow whatever order your artifact tools require.
   { "sample": {}, "downloads": true }
   - "sample" lets the page ask Claude to design.
   - "downloads" lets the page save PNG images and a .zip.
   Don't add connectors or any other capability.

4. Report back with the link to the new artifact, and remind me that the first design click asks me to allow the page to use Claude, and that designing uses my own Claude usage.

5. Don't upload or generate any content in it. Stop after step 4.

If your tools can't do part of this, tell me plainly which step failed and what I should do. Don't fall back to rebuilding the page from scratch.

Step 3. Upload your content and brand

  1. Open your new artifact. The globe is empty.
  2. Upload your .json or .csv plan. Posts that need a visual are selected for you. Text posts are optional.
  3. Set your brand name, three colours and two fonts. Add your logo and photos if you want them.

Step 4. Approve your style

Click Design 3 samples. To change them, write what you want under "How should it look?" and design the samples again. When you are happy, click Approve style.

Step 5. Create your visuals

Tick the posts you want, or click First 7 days, then Design selected. Each tile on the globe fills in as its visual is ready. You can click Stop at any time.

Usage

Designing uses your own Claude usage. Start with one week before doing the whole month. Quick draft makes rough layouts from your own text without using Claude.

Step 6. Review and download

Click a tile to preview it. Ask for a change and click Redesign. Then use Download this image or Download all (.zip).

Download before you close the page

Your plan, photos and designs are not saved inside the artifact. If you close or reload it, they are gone, so download your images first.

Check before you post: spelling, facts and prices, readability on your phone, and that you have the right to use every photo.

Troubleshooting

If something goes wrong

What you seeWhat to do
"Claude: not available in this view"Open the artifact inside claude.ai, not as a downloaded file.
"Reddit research: connect Parallel Search…"Add the Parallel Search connector, then reload the artifact.
"Scheduling: optional: add the Composio connector"Add the connector with the exact name Composio, then reload.
A post shows needs connectionClick the "Connect … ↗" button that appears, sign in to that app inside Composio, then schedule again.
A post shows needs mediaInstagram, TikTok and Shorts require an image or video, and the planner writes text only. Add media in your scheduling app.
"You have hit a usage or rate limit"Wait a while, then run again. Posts that were already written are kept.
Claude could not publish the artifactCheck that artifacts are turned on in your Claude settings, and use a normal chat in claude.ai or the desktop app. Claude Code cannot publish artifacts.
Visual Studio: your plan will not uploadUse the .json or .csv file downloaded from the planner, unedited.
Visual Studio: designs look off-brandCheck your colours and fonts, describe the look under "How should it look?", and design the samples again before you approve.
Visual Studio: text gets cut offOpen the tile. If it says text was shortened, ask for shorter text and click Redesign, then check it on your phone.
Visual Studio: "Claude is not available in this view"Open the published artifact inside Claude, not the downloaded file.
Visual Studio: usage limitWait a while, then continue with a smaller batch, such as one week.
