How to use them

  1. Open ChatGPT and select Create image.
  2. Upload your photo.
  3. Type one shortcut from the tables below, for example /high-fashion.
  4. Look at what it creates, then try another shortcut on the same photo.

ChatGPT doesn't have these slash commands built in. If it replies as if it doesn't understand one, paste this once at the start of the chat, then use the shortcuts as normal.

Paste first
When I upload a photo and type a slash shortcut such as /high-fashion or /fisheye, restyle my photo in the style named by the shortcut. Keep my face, outfit and hairstyle exactly the same unless I say otherwise. Create the image straight away without asking questions.

Make it yours

Tweak the result

After the first image, keep going in the same chat. You can ask it to:

  • Keep your face, outfit or hairstyle the same.
  • Change anything you don't like: the colours, the background, the mood.
  • Try a different shortcut on the same photo.
